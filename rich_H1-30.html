SBS 공식 프로그램 페이지는 《굿파트너2》를 「방영예정 11월 20일 금요일 밤 9시 50분 첫방송」이라고 적습니다. 오늘 2026년 10월 25일(일)부터 26일 뒤이고, 날짜는 금요일입니다.

 

이 글은 SBS 공식 페이지를 2026년 10월 25일에 직접 열어 확인한 것만 적었고, 몇 부작인지, OTT에서 보는지, 시즌1 다시보기 경로는 공식 페이지에서 확인하지 못했습니다.

 

확인하지 못한 항목은 따로 표시했습니다.

⭐ 소개 / 국내 최초 이혼 로펌의 대표 변호사 차은경이 파트너와 손잡고 도전에 나서는 휴먼 법정 오피스 드라마(SBS 소개 문구)

⭐ 시즌1 / SBS 시즌1 페이지에 「방영종료 전회차 무료!」라고 표기돼 있음

1. 공식 페이지에서 확인된 것

⭐ 작품 / 내용: 굿파트너2 (SBS 드라마) / 출처: SBS 공식 프로그램 페이지

⭐ 방송 일시 / 내용: 방영예정 11월 20일 금요일 밤 9시 50분 첫방송 / 출처: SBS 공식 프로그램 페이지(og:description)

⭐ 작품 소개 / 내용: 국내 최초 이혼 로펌의 대표 변호사 차은경이 지독한 인연의 파트너와 손잡고 피할 수 없는 도전에 나서는 휴먼 법정 오피스 드라마 / 출처: SBS 공식 프로그램 페이지 소개 문구

⭐ 시즌1 표기 / 내용: 굿파트너 — 「방영종료 전회차 무료!」 / 출처: SBS 시즌1 프로그램 페이지(og:description)

⭐ 몇 부작·OTT·다시보기 / 내용: 확인하지 못함 / 출처: 공식 페이지에 없음

「방영예정」은 편성 변경 가능성이 있는 표기입니다. 방송일이 가까워지면 SBS 프로그램 페이지의 표기가 「방영중」이나 다른 일정으로 바뀌는지 다시 확인해야 합니다.

 

 

2. 첫방송까지 며칠

ℹ️ 🧮 날짜 계산 — 달력에 첫방송 날짜를 대입했습니다 —

 

⭐ 오늘 2026년 10월 25일(일) → 첫방송 11월 20일(금) / 계산: 10월 남은 6일 + 11월 20일 / 결과: 26일

⭐ 방송 시각 밤 9시 50분 / 계산: 21:50 시작 / 결과: 1회분의 방송 길이는 공식 페이지에 없어 종료 시각은 계산하지 않음

⭐ 매주 금요일 방송이라면 같은 요일 반복 / 계산: 11/20 → 11/27 → 12/4 / 결과: 편성이 매주 금요일인지는 공식 페이지에 없어 날짜 목록은 참고용

공식 페이지에는 첫방송 일시만 있고 이후 회차 편성은 없습니다. 위 11/27·12/4는 금요일 방송이 이어진다고 가정했을 때의 날짜일 뿐 확인된 편성이 아닙니다.

 

 

3. 어떻게 볼까 — 확인된 길과 못 한 길

⭐ SBS 본방송(11/20 금 밤 9시 50분) / 확인 상태: 확인됨 / 근거: SBS 공식 방송 일시 표기

⭐ 시즌1 복습 / 확인 상태: 부분 확인 / 근거: 시즌1 페이지에 「방영종료 전회차 무료!」 표기. 어디에서 무료인지(SBS 사이트·앱·제휴 플랫폼)는 이 글에서 확인하지 못함

⭐ 시즌2 다시보기 / 확인 상태: 확인 못 함 / 근거: 공식 페이지에 다시보기 경로가 없음

⭐ OTT(웨이브·넷플릭스 등) 공개 / 확인 상태: 확인 못 함 / 근거: 공식 페이지에 OTT 언급이 없음. 자동완성에는 「굿파트너2 ott」가 뜨지만 검색되는 말이라는 뜻일 뿐 공개 사실이 아님

첫방송 전에 확인된 선택지는 본방송뿐이고, 시즌1 무료 표기는 복습 후보입니다. 방송이 가까워지면 SBS 프로그램 페이지의 다시보기·OTT 안내를 다시 열어 보세요.

 

다른 OTT 요금제 비교는 OTT 요금제 비교에 정리돼 있습니다.

 

 

4. 헷갈리기 쉬운 것

⭐ 금요일입니다: SBS 공식 표기는 「금요일」이고, 토요일 편성 여부는 확인하지 못했습니다.

⭐ 「방영예정」은 확정 편성이 아닙니다: 방송 직전에 바뀔 수 있습니다.

⭐ 시즌1 「무료」는 시즌2 「무료」가 아닙니다: 표기는 시즌1 페이지에만 있습니다.

⭐ 몇 부작은 시즌1 정보와 섞지 마세요: 시즌1의 회차 수를 시즌2에 그대로 쓸 수 없습니다.

⭐ OTT 검색어는 공개 사실이 아닙니다: 사람들이 많이 찾는다는 뜻일 뿐입니다.

 

5. 확인하지 못한 것

⚠️ 아래는 공식 자료에서 찾지 못해 적지 않았습니다

⭐ 몇 부작인지 — SBS 공식 페이지에 없습니다

⭐ OTT 공개 여부·플랫폼 — 공식 페이지에 언급이 없습니다

⭐ 시즌2 다시보기 경로 — 확인하지 못했습니다

⭐ 시즌1 「전회차 무료」가 어디서인지 — 표기만 확인했고 이용 경로는 열지 못했습니다

⭐ 토요일 편성 여부와 이후 회차 일정 — 공식 페이지는 첫방송 일시만 적습니다

⭐ 출연진·제작진 — 이 글에서는 다루지 않았습니다
