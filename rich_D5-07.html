무인점포를 하다 보면 같은 사람이 물건을 들고 나가는 CCTV 화면을 보게 됩니다. 속이 타서 그 장면을 출입문에 붙이고 싶어지는데, 그 사진 한 장이 점주를 피고소인으로 만들 수 있습니다.

 

정책브리핑(2026년 10월 23일)이 소개한 두 사건은 모두 점주에게 벌금 200만 원이 나왔습니다. 이 글은 붙이면 안 되는 것·해도 되는 것·피해를 돌려받는 순서를 법조문으로 확인해 정리했습니다.

 

핵심은 사진을 붙이지 말고, 기록을 모아 신고하고, 돈은 절차로 받는다는 것입니다.

1. 이 행동은 해도 되나? 상황별 판정표

점주가 실제로 하게 되는 행동을 여섯 가지로 나눴습니다. 이유는 조문 내용과 법원이 본 사례(정책브리핑 소개)를 근거로 한 설명입니다.

 

⭐ 「CCTV 녹화 중」 안내문 부착 / ✅ 해도 됨 / CCTV를 운영하는 사람은 안내판 등으로 알려야 하는 의무가 있습니다(개인정보 보호법 제25조 제4항)

⭐ 도둑 사진을 출입문에 부착 / ⛔ 위험 / 출입문은 누구나 보는 곳이라 「공연성」 요건에 해당. 진짜 도둑이어도 사실 적시 명예훼손이 성립할 수 있음

⭐ 얼굴을 흐리게 처리해 부착 / ⛔ 위험 / 알아볼 수 있는지가 기준. 옷·체형·장소·문구로 특정되면 같은 문제

⭐ SNS·동네 카페에 사진 게시 / ⛔ 더 위험 / 비방 목적이 인정되면 정보통신망법이 적용되어 형량이 형법보다 무거움

⭐ 현장에서 마주쳐 붙잡기 / ⚠️ 조건부 / 현행범은 누구나 영장 없이 체포 가능(형사소송법 제212조). 다만 곧바로 경찰에 넘겨야 하고 과한 물리력은 별도 책임

⭐ CCTV 원본·결제 기록 정리 후 경찰 신고 / ✅ 정석 / 수사기관을 통하는 길. 합의·배상명령 모두 이 단계가 출발점

 

2. 법이 정한 선 vs 법원이 본 선

점주 입장에서 가장 억울한 대목이 「사실인데 왜 죄냐」입니다. 조문과 실제 판단이 어긋나 보이는 지점을 놓았습니다.

 

⭐ 사실이면? / 조문의 문구: 형법 제307조 제1항 — 사실을 적시해도 명예훼손 성립 / 실제 법원 판단(정책브리핑 소개 사례): 도둑이 맞아도 처벌 대상

⭐ 면책 규정 / 형법 제310조 — 진실한 사실이고 오로지 공공의 이익에 관한 때에는 처벌하지 않음 / 「다른 피해를 막으려고 붙였다」는 항변이 받아들여지지 않았다고 정책브리핑은 설명

⭐ 얼굴 가림 / 조문에 규정 없음 / 인천 사례: 얼굴을 반투명 처리했어도 1심 무죄 → 항소심 유죄(명예훼손·아동학대, 벌금 200만 원). 학교 근처라 알아볼 수 있었다는 이유

⭐ 범죄 예방 목적 / 개인정보 보호법 제25조 — 범죄 예방·수사 목적의 CCTV 설치·운영은 가능 / 서울 강서구 사례(2024년 말): 항소심은 예방이 목적이면 얼굴 전체를 가리는 방법도 있었다고 지적, 벌금 200만 원

왜 이렇게 엄격한가: 피해자가 직접 응징하는 「자력구제」를 형사사법은 엄격히 막는다는 취지가 판단에 들어 있다고 정책브리핑은 전합니다. 억울함과 처벌 여부는 별개입니다.

 

 

3. 처벌 수위 한눈에 — 사진 게시와 온라인 게시

⭐ 가게 출입문·벽(오프라인) / 적용 조문 형법 제307조 제1항 / 법정형(상한) 징역·금고 2년, 벌금 500만 원

⭐ SNS·카페(비방 목적 인정 시) / 적용 조문 정보통신망법 제70조 제1항 / 법정형(상한) 징역 3년, 벌금 3천만 원

⚠️ 위 금액은 「상한」입니다. 실제 선고는 사안마다 다릅니다. 두 사건에서 나온 벌금 200만 원은 정책브리핑이 소개한 결과이며, 같은 행동이면 항상 그 금액이 나온다는 뜻이 아닙니다. 이 글은 법률 자문이 아니므로 이미 게시했다면 지체 없이 내리고 전문가 상담을 받으세요.

 

 

4. 신고 전 해야 할 일 — 피해 정리표 만들기

순서는 세 가지입니다.

 

⭐ ① 결제 기록 대조 — 키오스크·카드사·간편결제 내역으로 진짜 미결제인지

⭐ ② CCTV 원본을 날짜·시간별로 따로 저장 — 기간이 지나면 자동 삭제될 수 있음

⭐ ③ 피해 품목·금액·날짜 정리

세 번째가 중요한 이유는 뒤의 배상명령 조문에 있습니다. 소송촉진 등에 관한 특례법 제25조 제3항은 피해 금액이 특정되지 않으면 배상명령을 할 수 없다고 정해 두었습니다. 정리표는 이런 모양이면 됩니다.

 

아래 숫자는 설명을 위한 가상 예시입니다.

 

⭐ 10/05 21:10 / 아이스크림 / 6×1,500원 = 9,000원 / 결제 없음 / 1005_2110.mp4

⭐ 10/09 22:40 / 과자 / 4×1,800원 = 7,200원 / 2개 결제(3,600원) / 1009_2240.mp4

⭐ 10/12 20:55 / 음료 / 5×2,000원 = 10,000원 / 결제 없음 / 1012_2055.mp4

⭐ 가상 예시 피해액(미결제분만) / 9,000 + 3,600 + 10,000 = 22,600원

과자는 4개 중 2개만 결제됐으니 미결제 2개 = 3,600원만 셉니다. 결제분까지 넣으면 정리표의 신뢰가 깨집니다.

 

날짜·품목·금액·영상 파일명이 한 줄로 이어지면 경찰에 낼 자료도, 배상명령 신청 때 필요한 「금액 특정」도 한 번에 해결됩니다.

 

 

5. 돈을 돌려받는 3갈래 — 어느 길이 되나

⭐ ① 수사 중 합의 / 되는 경우: 범인이 특정된 뒤 피해액 배상·처벌 의사를 정리 / 안 되는 경우: 범인이 끝까지 특정되지 않으면 상대가 없음

⭐ ② 배상명령 / 되는 경우: 정식 형사재판에서 유죄가 선고될 때 법원이 직권 또는 신청으로 피해 배상을 명함(소송촉진법 제25조). 신청에 인지대 같은 비용이 들지 않는다고 정책브리핑은 설명 / 안 되는 경우: 피해 금액이 특정되지 않은 경우(같은 조 제3항 제2호), 약식 절차(벌금만 내고 끝)로 끝난 경우

⭐ ③ 민사 — 소액사건·지급명령 / 되는 경우: 금전 청구라면 지급명령을 신청할 수 있음(민사소송법 제462조). 소액사건은 간이한 절차 — 정책브리핑은 청구액 3000만 원 이하라고 소개 / 안 되는 경우: 지급명령은 공시송달 외의 방법으로 상대에게 송달할 수 있는 경우에 한함 → 상대 주소를 알아야 함

💡 실무 포인트: ①이 안 되고 ②도 약식으로 끝나면 ③으로 가는데, 이때는 상대의 주소·인적사항이 필요합니다. 구체적 절차는 법원 안내를 확인하세요.

 

 

6. 훔친 사람이 아이라면

⭐ 14세 미만이면 처벌되나? / 형사처벌 안 됨 / 형법 제9조 — 14세 되지 아니한 자의 행위는 벌하지 아니함

⭐ 그럼 배상도 못 받나? / 부모에게 청구할 길이 열려 있음 / 민법 제755조 — 책임능력 없는 사람이 입힌 손해는 감독할 법정의무자가 배상. 단 감독의무를 게을리하지 않았으면 면책

⭐ 아이 사진을 붙여 부모를 부르면? / ⛔ 가장 위험 / 서울 사례에서 항소심은 부모에게 합의를 압박하는 수단으로 봤다고 정책브리핑이 소개. 인천 사례는 아동학대까지 인정

아이가 대상이면 사진 공개 대신 CCTV 원본을 들고 경찰에 알리고, 부모에게는 정리표로 정중히 연락하는 쪽이 법적으로 안전합니다.

 

 

7. 범죄예방 장비 지원 — 우리 가게도 되나

소상공인 보호 및 지원에 관한 법률 제12조의9(2025년 12월 30일 신설, 법제처 현행 시행일자 2026년 7월 1일)가 근거입니다. 핵심만 풀면 이렇습니다.

 

⭐ 대상 / 상시 근로자 없이 혼자 사업하는 1인 소상공인, 여성이 소유·경영하는 소상공인(세부 기준은 대통령령)

⭐ 지원 내용 / 자기방어·도움 요청 물품 지급, CCTV·비상벨·AI 침입 감지 장치 같은 디지털 안전설비 설치 지원

⭐ 주체 / 중소벤처기업부 장관과 지방자치단체의 장이 사업을 「할 수 있다」(의무 규정이 아님)

⭐ 우선 지원 / 범죄 피해 우려가 높은 업종을 부령으로 정해 우선 지원할 수 있음

⚠️ 「법이 생겼다」와 「내가 받는다」는 다릅니다. 「할 수 있다」 규정이라 지자체가 사업을 열었는지, 신청 기간·금액이 어떤지는 지역마다 다릅니다. 정책브리핑은 부산·경기 화성 등이 조례를 고쳤거나 준비 중이라고 소개했습니다. 내 지역은 시·군·구청 지역경제 담당 부서에 직접 문의해야 합니다.

 

8. 확인하지 못한 것

⚠️ 공식 확인 실패 — 추측으로 채우지 않았습니다 (2026-10-24 기준)

⭐ 강서구·인천 두 사건의 판결문 원문과 사건번호 — 정책브리핑 기사 내용을 출처를 밝혀 인용했습니다

⭐ 소액사건 「3000만 원 이하」의 대법원규칙 조문 — 정책브리핑 소개를 인용했고, 소액사건심판법 제2조는 「대법원규칙으로 정하는 민사사건」이라고만 정합니다

⭐ CCTV 영상의 법적 보관기간 기준 — 확인하지 못해 숫자를 쓰지 않았습니다(기기 설정을 확인하세요)

⭐ 지자체별 범죄예방 장비 지원 금액·신청 기간·접수 창구

⭐ 4절 정리표의 숫자는 설명용 가상 예시이며 실제 피해액 인정 방식은 사건마다 다릅니다
