⭐ 대출 용도·기간 : 임차보증금(전세). 매매는 대상 아님. 1년 이상 2년 이내(임대차계약 만료일까지), 만기 일시 상환

⭐ 금리 : 연 3.5% — 소득 1억 이하 시 2.0%·자부담 1.5% / 1억 초과 시 1.8%·자부담 1.7%

2. 누가 되고 누가 빠지나

⭐ 대상(모두 충족) : 대출신청일 기준 혼인신고 7년 이내 또는 혼인 예정 3개월 이내 · 부부 합산 연소득 1억 3천만 원 이하 무주택 · 부부 모두 부산 주소 등재 · 확정일자부 임대차계약 체결 + 보증금 5% 이상 지불

⭐ 대상 주택 : 부산시 소재 임차보증금 4억 원 이하 주택(아파트 포함)·주거용 오피스텔. 면적 제한 없음, 월세(반전세)는 보증금이 있으면 가능

⭐ 제외(한 명이라도) : 기초생활수급자 · 부모(배우자 부모 포함)와 임대차계약 · 이 사업으로 대출을 실행한 적이 있는 사람(생애 1회) · 공공임대주택 거주자 · 주택도시기금 전세자금대출(버팀목 등)·다른 지자체 주거지원 수혜자

⭐ 예외 : 계약 만료 등으로 이사하려는 경우는 신청 가능(FAQ 2-14~17), 버팀목은 대출 실행일에 상환해 대환하면 가능

⭐ 신청 불가 : 부산으로 전입 예정인 사람(신청일 기준 부부 모두 이미 전입 필요, 최소 전입 기간은 없음) · 주택 보유자(처분 입증 시 예외) · 재외국민

부모님이 집을 갖고 계셔도 본인과 배우자가 무주택이면 가능하고, 오피스텔과 입주권·분양권(등기·잔금 전)은 주택 수에 넣지 않습니다.

 

소득은 근로자는 최근 연도 원천징수영수증, 사업자는 소득금액증명원, 소득이 없으면 신고사실없음 증명으로 확인합니다.

 

 

3. 얼마나 아끼나 — 가상 계산

ℹ️ 🧮 가상 사례 — 실제 신청자가 아니라 공고의 금리표에 가정한 대출액을 넣은 계산입니다(만기 일시 상환, 한도 2억 전액 대출 가정) —

 

⭐ 부부 합산 연소득 1억 원 이하 / 연 총이자: 700만 원 / 시 지원(연): 400만 원 (2.0%) / 본인 부담(연): 300만 원 (1.5%) · 월 약 25만 원

⭐ 부부 합산 연소득 1억 원 초과(1.3억 이하) / 연 총이자: 700만 원 / 시 지원(연): 360만 원 (1.8%) / 본인 부담(연): 340만 원 (1.7%) · 월 약 28만 3천 원

⭐ 보증금 3억 원 → 대출 한도 / 계산: min(2억, 3억 × 90% = 2.7억) / 결과: 2억 원

⭐ 보증금 2억 원 → 대출 한도 / 계산: 2억 × 90% / 결과: 1억 8천만 원(한도가 보증금에 묶임)

⭐ 기본 2년 시 지원 합계(소득 1억 이하, 2억 대출) / 계산: 400만 원 × 2 / 결과: 800만 원

⭐ 기본 2년 시 지원 합계(소득 1억 초과) / 계산: 360만 원 × 2 / 결과: 720만 원

⭐ 최대 10년 지원이 이어지는 이론상 상한(소득 1억 이하) / 계산: 400만 원 × 10 / 결과: 4,000만 원 (연장 요건 충족·대출금 유지 가정)

이자 지원을 이어 받는 연장은 지원 기간 중 임신(유산 포함)이나 출산이 있으면 자녀 1명당 1회 2년, 난임 시술을 1년 이상 받은 경우 1회 2년입니다.

 

총 지원기간은 10년을 넘지 못하고 같은 임신·출산으로 중복 연장되지 않습니다. 연장 심사에서는 소득을 보지 않고 금리는 최초 금리를 그대로 적용합니다.

 

위 금액은 산식값이며 실제 대출금·보증서 한도·대출 기간에 따라 달라집니다. 보증료(신용보증금액의 0.02%)는 신청인이 냅니다.

 

 

4. 신청 순서와 20영업일 규칙

⭐ ① 사전 상담 : 임대차계약 체결 후 필요하면 부산은행 영업점에서 자격·가능 금액 상담

⭐ ② 사업 신청 : 부산은행 모바일 뱅킹 앱 — 대출 → 대출신청관리 → 동의·약정·예약 → 신혼부부 전세자금대출 사전접수. 임대차계약서상 임차인 1명만 신청

⭐ ③ 서류 제출 : 영업점 방문. 신청 후 20영업일 이내 미방문 시 신청 자동 취소

⭐ ④ 심사·보증 : 부산은행 심사(약 1개월), 한국주택금융공사 보증서 발급

⭐ ⑤ 대출 실행 : 임대인 계좌로 입금. 실행 예정일은 사업 신청일 기준 20영업일부터 선택 가능

⭐ ⑥ 이차보전 : 부산시가 부산은행에 이자 지원금 지급

ℹ️ 🧮 가상 사례 — 신청일에 따라 고를 수 있는 가장 빠른 대출 실행 예정일(토·일만 제외, 공휴일 미반영 대략 계산) —

 

⭐ 11월 2일(월) / 20영업일 뒤: 11월 30일(월) / 해석: 11월 안에 실행 가능

⭐ 11월 16일(월) / 20영업일 뒤: 12월 14일(월) / 해석: 12월 중순 실행

⭐ 11월 30일(월) (마감일) / 20영업일 뒤: 12월 28일(월) / 해석: 12월 말 — 대출 실행기간(12월 31일)까지 며칠 안 남음

신규 임차는 잔금일과 전입일 중 빠른 날부터 3개월 이내에 신청해야 하고, 실행 예정일 20영업일 전에는 서류 제출을 끝내야 합니다.

 

잔금일이 12월 중순보다 이르다면 마감 직전에 신청하는 방식은 맞지 않을 수 있어서 가능하면 11월 초에 신청하는 것이 안전합니다. 12월 25일 같은 공휴일을 영업일에서 빼면 날짜가 하루씩 더 밀립니다.

 

실제 영업일 기준은 은행에 확인해야 합니다.

 

 

5. 헷갈리기 쉬운 것

⭐ 「최대 2%」는 모두에게 2%가 아닙니다: 부부 합산 소득 1억 원 이하만 2.0%p이고 초과는 1.8%p입니다. 1억 3천만 원을 넘으면 대상이 아닙니다.

⭐ 최대 2억 원은 한도일 뿐입니다: 실제 대출액은 보증서 발급 가능 금액과 신용에 따라 정해집니다.

⭐ 부산은행에서만 받습니다: 다른 은행 전세대출로는 이 이자 지원을 받을 수 없습니다.

⭐ 앱 신청만으로 끝나지 않습니다: 20영업일 안에 영업점을 방문해 서류를 내야 합니다.

⭐ 전입 예정은 안 됩니다: 신청일 기준 부부 모두 이미 부산에 전입돼 있어야 합니다.

⭐ 생애 1회입니다: 이 사업으로 대출한 적이 있으면 다시 못 합니다.

⭐ 버팀목과는 중복되지 않습니다: 버팀목 대출 중이면 신청 불가이고 대출 실행일에 상환해 대환하는 경우만 가능합니다.

⭐ 대출 실행 후 정당한 사유 없이 1개월 안에 대상 주택에 전입하지 않으면 이자지원이 중단됩니다. 중단 사유를 은행에 통보하지 않거나 늦게 통보하면 이자 지원금·대출금 즉시 회수, 대출만기 연장 제한, 연체이자 부과 등 불이익이 있을 수 있습니다.

⭐ 11월 30일에 신청하면 대출 실행은 빨라야 12월 말입니다: 신청과 실행 사이에 20영업일 이상이 필요하고, 심사·승인 결과는 별개입니다.
