부산 금정구 홍법사에서 10월 30일(금)~31일(토) 15:00~20:00 「가을엔 절로 페스타」가 열립니다(부산광역시 주최·부산관광공사 주관, 비짓부산 공식 안내). 사찰음식 명장 대안스님의 108가지 사찰음식 전시·체험, 천연염색·싱잉볼, 주지스님과 산책, 특별강연, 연등 아래 공연·피크닉이 이어집니다.

피크닉 패키지는 채움 35,000원(2인)·비움 15,000원(1인)·머묾 15,000원(1인)입니다. 현장 판매는 비짓부산 안내에 「현장판매」로 적혀 있으나 머묾 기준이며 패키지 전체인지는 확인하지 못했습니다.

비짓부산과 NOL 티켓 상품 페이지를 직접 열어 요금·취소 수수료·셔틀을 정리하되, 확인하지 못한 것은 박스에 남겼습니다.

🏮 먼저 정리

⭐ 일시·장소 — 10월 30일(금)·31일(토) 15:00~20:00 · 부산 금정구 홍법사(NOL 표기: 두구로33번길 202 홍법사 잔디광장 일원)

⭐ 요금 — 채움 35,000원/2인 · 비움 15,000원/1인 · 머묾 15,000원/1인 · 「현장판매」 표기는 머묾 기준(패키지 전체 여부 미확인) · 전시 관람과 일부 체험은 패키지 구매와 상관없이 무료

⭐ 예매·취소 — 사전예매 NOL 앱 · 관람 10일 전까지 취소 수수료 장당 2,000원(10% 이내), 날짜가 가까울수록 10→20→30%

⭐ 가는 길 — 14시부터 행사 종료까지 지하철 노포역↔홍법사 셔틀 순환 · 주차 협소

⭐ 채움 패키지는 NOL 가격표에서 확인하지 못했고, 세 패키지의 구성 내용·셔틀 배차 간격도 확인하지 못했습니다

⭐ 2인 방문 시 채움 35,000원이 비움·머묾(각 30,000원)보다 5,000원 더 비쌉니다(직접 계산)

1. 일정과 프로그램

⭐ 일시 / 10월 30일(금)~31일(토) 15:00~20:00, 하루 5시간 · 이틀 합계 10시간(직접 계산)

⭐ 장소 / 부산 금정구 홍법사

⭐ 사찰음식 / 사찰음식 명장 대안스님 — 108가지 사찰음식 전시·체험

⭐ 체험 / 천연염색 · 싱잉볼

⭐ 프로그램 / 주지스님과 산책 · 특별강연 · 연등 아래 공연·피크닉

⭐ 주최·주관 / 부산광역시 · 부산관광공사

⭐ 비짓부산 주소 표기는 「두구로 33번길」(번지 없음)이고 NOL 표기는 「두구로33번길 202 홍법사 잔디광장 일원」입니다. 길 찾기에는 번지가 있는 NOL 표기가 편합니다

2. 패키지 3종 — 요금 비교

⭐ 채움 / 35,000원 / 2인 / 1인당 17,500원 / 2인 방문 시 35,000원 / NOL 가격표 확인 못 함

⭐ 비움 / 15,000원 / 1인 / 1인당 15,000원 / 2인 방문 시 30,000원 / 30일·31일 각 1인 15,000원 확인

⭐ 머묾 / 15,000원 / 1인 / 1인당 15,000원 / 2인 방문 시 30,000원 / NOL 가격표 확인 못 함

⭐ 「현장판매」 표기는 머묾에 붙어 있어 다른 패키지의 현장 판매 여부는 확인하지 못했고, 전시 관람과 일부 체험은 패키지를 사지 않아도 무료입니다

⭐ 2인이 가면 채움(35,000원)이 비움·머묾(2×15,000원)보다 5,000원 비쌉니다. 세 패키지에 무엇이 들어가는지는 확인하지 못해 가격만 비교했습니다

⭐ 비짓부산 게시와 NOL 가격표가 달라 보이는 부분(채움)은 매진·미노출 여부를 알 수 없습니다. 현장 판매 가능성은 비짓부산 안내에 적혀 있습니다

3. 예매·취소 수수료 계산예시

NOL 상품 페이지의 취소 규정입니다. 예매 가능 시간은 관람 전일 23:59까지이고, 예매 후 7일 이내 취소는 전액 환불(수수료 제외)입니다. 오늘(10월 18일)은 10월 30일 행사 기준 12일 전입니다.

⭐ 10일 전까지 / 장당 2,000원(10% 이내) / 10/30(금) 관람 시 ~10/20 / 비움 15,000원 1장: 10% 15,000×10% = 1,500원, 최대 2,000원

⭐ 9~7일 전 / 10% / 10/21~10/23 / 1,500원

⭐ 6~3일 전 / 20% / 10/24~10/27 / 3,000원

⭐ 2일 전~ / 30% / 10/28~ / 4,500원

⭐ 31일(토) 관람권은 위 날짜가 하루씩 뒤로 갑니다(예: 10일 전 = 10/21)

⭐ 「장당 2,000원(10% 이내)」은 15,000원 티켓에서는 10%인 1,500원이 더 낮아 실제 수수료가 1,500~2,000원 사이일 수 있습니다. 정확한 금액은 NOL 안내(문의 1544-1555)로 확인하세요

⭐ NOL 가격표에서 확인된 상품은 비움이라 위 예시는 비움 15,000원으로 계산했고, 채움 35,000원은 같은 비율을 적용한 것이 아니라 확인하지 못했습니다

4. 노포역 셔틀과 주차

⭐ 셔틀버스 / 14시부터 행사 종료까지 지하철 노포역 ↔ 홍법사 순환

⭐ 주차 / 협소

⭐ 배차 간격 / 안내 없음(확인 못 함)

⭐ 행사 시작이 15시이고 셔틀이 14시부터 다니니, 노포역에서 홍법사로 가는 셔틀을 이용하는 쪽이 주차보다 수월해 보입니다(해석)

⭐ 야간 기온이 떨어진다는 안내가 있어 20시 종료 무렵의 이동 시간도 고려해야 합니다

5. 가기 전에 알아둘 것

⭐ 투명텐트 — 2인 1동이며 현장 접수순으로 배정합니다

⭐ 음주·흡연 금지 — 사찰 경내 행사라 지켜야 합니다

⭐ 반려동물 — 안전장치를 한 경우에 한해 제한적으로 출입할 수 있습니다

⭐ 야간 기온 — 해가 진 뒤 기온이 내려가니 겉옷을 챙기세요

⭐ 문의 — NOL 티켓 고객센터 1544-1555
