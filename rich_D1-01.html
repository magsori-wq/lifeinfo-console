행·회사 제출·부동산 계약 때 자주 필요한 주민등록등본, 이제 주민센터 안 가도

정부24에서 집에서 무료로 뽑아요. 처음 하는 분도 따라 할 수 있게 발급 순서랑

등본·초본 차이, 무인발급기·수수료까지 정리했습니다.

등본 vs 초본 (먼저 확인)

• 주민등록표 등본 — 같은 주소 세대 구성원 전체. 가족 단위 증명(전·월세, 학자금 등)

• 주민등록표 초본 — 본인 1명의 인적사항 + 주소 변동 이력. 과거 거주지·병역·재산 서류 등

→ 둘 다 정부24에서 같은 방식. 발급 단계에서 표시 항목(세대원·주소변동 포함) 직접 선택

준비물

• 본인 인증 — 공동인증서 또는 간편인증(카카오·네이버·통신사 PASS 등)

• 프린터 (없으면 PDF 저장·무인발급기 활용)

※ 회원가입 없이 비회원 발급도 가능(단 본인 인증은 필요)

정부24 인터넷 발급 순서 (3분)

1) 포털에서 '정부24' 검색 → 공식 홈페이지(www.gov.kr) 접속

2) 검색창에 '주민등록표 등본' 입력 → 발급

3) 로그인 또는 간편인증으로 본인 확인 (비회원 가능)

4) 표시 항목(세대주·세대원, 과거 주소 변동 이력 포함 여부 등) 선택

5) '민원 신청하기' → 출력 또는 PDF 저장

💡 제출처가 '주소 변동 이력 포함'을 요구하는 경우 많음 → 발급 때 옵션 체크해야 인정.

정부24 문서엔 위변조 확인용 '문서확인번호'가 찍혀 출력본도 진위 확인 가능

프린터 없을 때

• 정부24 모바일 앱 — 발급 문서를 전자문서지갑에 보관 → 제출 기관으로 바로 전송

• 무인민원발급기 — 주민센터·지하철역·대형마트 등. 지문·신분증 확인 후 즉시 출력

(2024.5.30~ 주민등록등·초본 등 주요 8종 무인발급 수수료 무료)

발급처별 수수료

• 정부24 인터넷 — 무료 (PC·모바일·PDF)

• 무인민원발급기 — 무료 (2024.5.30~ 주요 8종 면제)

• 주민센터 방문 — 1통 400원 (이해관계인 교부 500원)

→ 인터넷·무인발급기는 무료, 창구 방문만 소액

※ 가족관계증명서·건강보험 자격득실확인서 등 수백 종 민원서류도 정부24에서 같은 방식
