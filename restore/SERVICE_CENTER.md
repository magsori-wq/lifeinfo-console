# 서비스센터 접수용 요청서

이 페이지를 접수 담당자에게 그대로 보여주세요.

---

## ⛔ 가장 중요 — 먼저 읽어주세요

> **Windows 재설치·포맷·초기화를 하지 말아 주세요.**
>
> `C:\lifeinfo` 폴더에 백업이 없는 업무 데이터가 있습니다.
> 이 폴더가 사라지면 복구할 수 없습니다.
>
> 재설치가 꼭 필요하다고 판단되시면 **작업 전에 반드시 연락 주세요.**
> `C:\lifeinfo` 폴더 전체를 USB에 복사한 뒤에 진행하겠습니다.

---

## 증상

1. **노트북 내장 화면(주 모니터)이 고장난 상태**입니다. 이건 이전부터 있던 문제이고,
   그동안 **외부 모니터를 연결해서 정상적으로 사용**하고 있었습니다.
2. 최근 PC 문제를 조치하는 과정에서 **안전모드(안전부팅)로 부팅되도록 설정이 저장**되었습니다.
3. 안전모드에서는 외부 모니터로 출력이 되지 않습니다.
   그래서 **지금은 아무 화면도 볼 수 없어 조작이 불가능한 상태**입니다.

---

## 요청 사항

### 요청 1 — 안전부팅 해제 (가장 급함)

BCD의 safeboot 플래그를 제거해 주세요.

```
bcdedit /deletevalue {current} safeboot
bcdedit /deletevalue {default} safeboot
```

또는 `msconfig` → 부팅 → **안전 부팅 체크 해제**.

이것만 해제되면 정상 모드로 부팅되고, **외부 모니터가 예전처럼 다시 켜집니다.**
안전모드 이전에는 외부 모니터로 문제없이 사용하고 있었으므로,
**내장 패널을 수리하지 않아도 업무 복귀가 가능합니다.**

### 요청 2 — 데이터 백업 (USB 지참했습니다)

`C:\lifeinfo` **폴더 전체**를 제공한 USB에 복사해 주세요.
특히 아래 두 폴더가 중요합니다:

- `C:\lifeinfo\studio\`
- `C:\lifeinfo\posts\`

### 요청 3 — 외부 모니터를 주 디스플레이로 설정

복구 후, 설정 → 시스템 → 디스플레이에서
외부 모니터를 선택하고 **"이 디스플레이를 주 디스플레이로 만들기"** 를 체크해 주세요.
내장 패널이 고장난 상태이므로, 이렇게 해두면 다음 부팅부터 바로 화면이 보입니다.

### 요청 4 — 원격 데스크톱 활성화 (가능하면)

설정 → 시스템 → 원격 데스크톱 → **켜기**.
다음에 같은 문제가 생기면 다른 PC에서 접속해 조치할 수 있습니다.

### 요청 5 — 내장 패널(액정) 교체

액정을 교체해 주세요. 교체 비용을 먼저 알려주시면 확인하고 진행하겠습니다.

> **액정이 교체되면 안전모드 문제도 함께 풀립니다.**
> 내장 화면이 보이게 되므로, 안전모드로 부팅되더라도 화면을 보면서
> `msconfig` 에서 안전부팅을 직접 해제할 수 있습니다.
> 그래도 **요청 1(안전부팅 해제)을 함께 처리해 주시면** 받아가서 바로 정상 사용이 가능합니다.

## 참고 정보

- **BitLocker 복구 키**: 디스크 암호화가 걸려 있을 수 있습니다.
  필요하면 Microsoft 계정에서 확인해 드리겠습니다 —
  https://account.microsoft.com/devices/recoverykey
- 안전모드로 들어가기 전까지는 **외부 모니터 + 노트북 조합으로 정상 작동**했습니다.
  즉 그래픽 드라이버와 외부 출력 포트는 정상입니다.
- 강제 종료(전원 버튼 길게 누름)를 1회 실행한 상태입니다.

# 복구 직후 반드시 할 일

1. **`studio\` 를 private GitHub 저장소에 백업.**
   현재 `lifeinfo-console` 은 GitHub Pages 공개 저장소이므로 자격증명이 섞이면
   유출됩니다. `studio\` 는 반드시 private 쪽으로.
2. `C:\lifeinfo\CLAUDE.md` 에 아래 규칙 추가 — 같은 사고 재발 방지:

   > **디스플레이 안전 규칙**: 이 PC는 노트북 내장 패널이 고장나 **외부 모니터
   > 1대만으로 동작한다.** 따라서 다음을 **제안하거나 실행하지 말 것**:
   > 안전모드(safeboot) 부팅, `bcdedit` 부팅 설정 변경, 디스플레이 드라이버
   > 제거·롤백, 그래픽 어댑터 비활성화. 이런 조치는 화면 출력을 잃게 만들어
   > 복구가 불가능해진다. 부팅 설정 변경이 정말 필요하면 **먼저 사용자에게
   > 화면 접근 수단(원격 데스크톱 등)을 확보했는지 확인**한 뒤에만 진행한다.

3. 원격 데스크톱을 켜 둔다 (또는 RustDesk 설치) — 화면이 죽어도 다른 PC에서 들어갈 수 있게.
