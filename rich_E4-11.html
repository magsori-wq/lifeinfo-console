2026년 6월 16일 공포된 부동산 거래신고 등에 관한 법률 개정(법률 제21815호)은 인터넷에 올리는 부동산 광고에 없는 매물이나 거짓·과장 가격을 올리면 과태료 500만원 이하(제28조제2항제5호)를, 거짓 개발정보 등으로 거래를 유인하면 1년 이하 징역 또는 2천만원 이하 벌금(제26조제4항)을 정했습니다.

 

두 조항은 공포 후 6개월이 지난 2026년 12월 17일부터 시행됩니다.

 

직거래 플랫폼 운영사업자의 본인 확인 의무는 공포 후 1년, 2027년 6월 17일부터입니다(공포일 기준으로 계산한 날짜). 국가법령정보센터에서 개정법 원문을 직접 열어 확인한 것만 적었고, 확인하지 못한 것은 따로 표시했습니다.

⭐ 거짓 개발정보 유포 / 거래를 유인할 목적이면 1년 이하 징역 또는 2천만원 이하 벌금

1. 무엇이 어떻게 바뀌나 — 조문별 비교

⭐ 제23조의2 허위정보 유포 금지 / 거래를 유인할 목적으로 거짓 개발정보, 확정되지 않은 계획을 확정된 것처럼 전하는 정보, 수요·공급·가격 현황을 의도적으로 왜곡한 정보를 퍼뜨리는 것 금지 / 시행 2026.12.17. / 제재 제26조제4항: 1년 이하 징역 또는 2천만원 이하 벌금

⭐ 제23조의3제1항 필수정보 명시 / 인터넷으로 부동산 거래(임대차 포함)를 광고할 때 소재지·면적·가격 등(대통령령) 명시. 개업공인중개사가 의뢰받은 광고는 제외 / 시행 2026.12.17. / 제재 이 글이 읽은 벌칙·과태료 조문에서 제1항 위반의 제재는 확인되지 않음

⭐ 제23조의3제2항 부당 표시·광고 금지 / 존재하지 않아 거래할 수 없는 매물, 가격 등을 거짓·과장한 광고 등 / 시행 2026.12.17. / 제재 제28조제2항제5호: 500만원 이하 과태료(착오·경미한 과실로 사실과 다르게 기재한 경우 제외)

⭐ 제23조의4 직거래 플랫폼 운영사업자 의무 / 게시자 본인 여부·소유자와의 관계 등 확인 후 확인 여부를 광고에 표시, 직거래 유의사항 안내 / 시행 2027.6.17. / 제재 제28조제2항제6호: 500만원 이하 과태료

⭐ 제23조의5 인터넷 광고 모니터링 / 국토교통부장관이 준수 여부 모니터링, 플랫폼에 자료 제출·확인·추가정보 게재 등 조치 요구 / 시행 2027.6.17. / 제재 제28조제2항제7·8호: 정당한 사유 없이 따르지 않으면 500만원 이하 과태료

시행일은 부칙을 기준으로 적었습니다. 부칙은 법 전체를 공포 후 6개월, 다만 제23조의4·제23조의5·제28조제2항제6~8호는 공포 후 1년으로 정합니다.

 

 

2. 나는 어디에 해당하나 — 판정표

⭐ 직접 인터넷에 매물을 올리는 개인(직거래) / 필수정보 명시(제23조의3제1항)와 부당 광고 금지(제2항) 대상. 존재하지 않는 매물·거짓 가격은 과태료 500만원 이하. 착오·경미한 과실로 사실과 다르게 적은 경우는 과태료에서 제외. 다만 제23조의3제1항의 「표시·광고」는 대통령령으로 정하는 것만 해당하므로 모든 게시글이 필수정보 명시 대상인지는 시행령 확인 전까지 단정할 수 없음

⭐ 개업공인중개사로서 의뢰받은 매물을 광고 / 필수정보 명시 조항에서는 제외(공인중개사법 제18조의2 광고). 부당 표시·광고 금지는 「누구든지」 적용이라 별개로 확인 필요

⭐ 매물을 찾는 매수인·임차인 / 이 조항들은 게시자와 플랫폼의 의무입니다. 소비자가 지는 의무는 조문에 없습니다

⭐ 카페·유튜브 등에서 개발 호재를 알리는 사람 / 거래를 유인할 목적으로 거짓 개발정보 등을 유포하면 징역·벌금 대상(제26조제4항)

⭐ 직거래 플랫폼 운영사업자 / 2027.6.17.부터 게시자 본인 여부·소유자와의 관계 확인 후 표시, 유의사항 안내 의무

 

3. 가상 사례 — 5개 판정

🧮 실제 매물·게시자가 아니라 조문 요건을 대입해 본 정리입니다

 

⭐ 이미 계약된 아파트를 계속 「즉시 입주 가능」으로 게시 / 제23조의3제2항제1호: 존재하지 않아 거래할 수 없는 부동산등 / 시행 후 부당 광고에 해당할 수 있음, 과태료 500만원 이하

⭐ 실제 월세 70만원을 50만원으로 올림 / 제2항제2호: 가격을 사실과 다르게 표시 / 부당 광고에 해당할 수 있음(착오·경미한 과실이면 과태료 제외)

⭐ 「역 신설 확정」이라며 아직 확정되지 않은 계획을 사실처럼 홍보 / 제23조의2제2호: 확정되지 않은 개발 계획을 확정된 사실로 오인되게 제공 / 거래를 유인할 목적이면 징역·벌금 대상(제26조제4항)

⭐ 중개사무소가 의뢰받은 매물을 광고 / 제23조의3제1항 괄호: 개업공인중개사 의뢰 매물 광고 제외 / 필수정보 명시 조항 대상이 아님

⭐ 매물 광고에서 소재지만 쓰고 면적·가격을 안 씀 / 제23조의3제1항: 필수정보 명시 의무 / 항목은 대통령령, 위반 제재는 이 글이 읽은 조문 목록에 없음 → 확인 못 한 영역

 

4. 허위매물 의심 점검 5문항

🔎 이 글의 판단 — 조문이 금지하는 행위를 소비자 눈으로 옮긴 점검표입니다(공식 판별 기준이 아닙니다)

 

⭐ 가격이 주변 같은 조건 매물보다 이유 없이 크게 낮은가(제23조의3제2항제2호 거짓·과장 가격)

⭐ 게시자가 소유자와 어떤 관계인지 설명할 수 있는가 — 2027.6.17. 이후에는 플랫폼이 확인 여부를 표시해야 하지만 지금은 의무가 아닙니다

⭐ 소재지·면적·가격 같은 기본 정보가 빠졌는가(제23조의3제1항 필수정보)

⭐ 「호재 확정」이라고 단정하면서 공식 발표 자료를 보여 주지 못하는가(제23조의2제2호 확정되지 않은 개발 계획)

⭐ 현장 확인과 등기사항증명서(등기부) 확인을 서두르지 말라고 하는가 — 열람은 인터넷등기소에서 할 수 있는지 먼저 확인하세요(요금·절차 상세는 이 글에서 확인하지 못함)

위 항목은 위법 판단 근거가 아니라 의심 단서입니다. 한 가지라도 걸리면 계약금을 보내기 전에 소유자·등기·현장을 직접 확인하세요.

 

 

5. 헷갈리기 쉬운 것

⭐ 「처벌」이 한 가지가 아닙니다: 허위매물 광고는 과태료(행정 제재), 거짓 개발정보 유포는 징역·벌금(형사 처벌)입니다. 이 글은 두 가지를 따로 적었습니다

⭐ 시행일이 둘입니다: 허위정보 유포 금지와 부당 광고 금지는 2026.12.17., 플랫폼 확인 의무와 모니터링은 2027.6.17.입니다. 법령 사이트의 조문별 표시와 부칙 단서가 달라 보일 수 있어 이 글은 부칙을 기준으로 적었습니다

⭐ 소비자의 의무가 아닙니다: 이 조문들은 광고를 올리는 사람, 개발정보를 퍼뜨리는 사람, 플랫폼 운영사업자를 대상으로 합니다

⭐ 중개사 광고는 필수정보 조항 제외: 개업공인중개사가 의뢰받은 매물 광고는 제23조의3제1항에서 빠집니다. 다만 부당 광고 금지(제2항)는 「누구든지」로 적혀 있습니다

⭐ 12/17 이전 게시물: 부칙에 경과규정이 없고, 시행 이전에 올린 글이 시행 이후에도 노출될 때의 적용은 확인하지 못했습니다

 

6. 확인하지 못한 것

⚠️ 아래는 공식 자료에서 찾지 못해 적지 않았습니다

⭐ 필수정보 항목 — 제23조의3제1항이 「소재지, 면적, 가격 등 대통령령」이라고만 합니다. 시행령 내용을 확인하지 못했습니다

⭐ 부당 표시·광고의 세부 유형·기준 — 국토교통부 고시(제23조의3제3항)를 확인하지 못했습니다

⭐ 플랫폼의 본인·소유자 확인 방식 — 제23조의4가 대통령령에 맡겼고 확인하지 못했습니다

⭐ 필수정보 명시 위반의 제재 — 이 글이 읽은 벌칙·과태료 조문에 제23조의3제1항 위반이 보이지 않았습니다

⭐ 신고 창구 — 공식 페이지에서 확인하지 못해 싣지 않았습니다

⭐ 인터넷등기소 등기부 열람 요금·방법 — 인터넷등기소 메인에서 해당 안내를 읽지 못해 싣지 않았습니다
