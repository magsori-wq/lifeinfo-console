2027년도 사회복무요원 본인선택 접수가 11월 10일(화) 10:00에 시작됩니다.

 

병무청 보도자료(2026-10-15)에 따르면 재학생입영연기·국외입영연기 중인 사람은 1차(11월 10일~16일), 소집대기 중인 사람 전원은 2차(12월 1일~7일)입니다.

 

비용은 없고 병무청 누리집이나 모바일 앱에서 원하는 소집일자와 복무기관을 2지망까지 고릅니다.

 

보도자료 전문을 직접 열어 내 상태에서 어느 접수가 맞는지, 마감 시각, 선착순이 아닌 선발 기준과 확인하지 못한 것을 정리했습니다.

 

📋 먼저 정리

 

⭐ 1차 대상 — 재학생입영연기 중인 사람 · 국외입영연기 중인 사람 / 접수 11월 10일(화) 10:00 ~ 11월 16일(월) 18:00 / 발표 11월 18일(수) 14:00

⭐ 2차 대상 — 사회복무요원 소집대기 중인 사람 전원 / 접수 12월 1일(화) 10:00 ~ 12월 7일(월) 18:00 / 발표 12월 9일(수) 14:00

⭐ 어디서 — 병무청 누리집(www.mma.go.kr) 또는 병무청 모바일 앱 · 본인인증(병무청 간편인증·공동인증서·나라사랑이메일 인증 등) 후 소집일자와 복무기관을 2지망까지

⭐ 선발 — 전공·미선발 횟수·나이·직업선호 유형 등을 고려합니다. 신청 순서(선착순)로 정한다는 설명은 원문에 없습니다

⭐ 돕는 기능 — 복무기관을 고르기 쉽도록 실시간 접수현황을 제공

⭐ 오늘(10월 19일)부터 1차 시작까지 22일입니다(직접 계산)

⭐ 소집일자 목록, 선발 항목별 비중, 미선택 시 배정 방식은 보도자료에서 확인하지 못했습니다

1. 내 상태별 어느 접수인가 — 판정표

보도자료의 접수일정표를 내 상태 기준으로 다시 풀었습니다.

 

⭐ 재학생입영연기 중 / 1차 / 11/10(화) 10:00 ~ 11/16(월) 18:00 / 발표 11/18(수) 14:00

⭐ 국외입영연기 중 / 1차 / 11/10(화) 10:00 ~ 11/16(월) 18:00 / 발표 11/18(수) 14:00

⭐ 사회복무요원 소집대기 중(전원) / 2차 / 12/1(화) 10:00 ~ 12/7(월) 18:00 / 발표 12/9(수) 14:00

⭐ 1차 대상인데 1차에 신청하지 못한 경우 / 2차에 신청할 수 있는지는 확인하지 못했습니다

⭐ 1차는 두 가지 연기 상태(재학생·국외)에만 열려 있고, 2차는 소집대기 중인 사람 전원이 대상입니다

⭐ 1차 대상자가 2차에도 신청할 수 있는지, 본인선택을 하지 않으면 어떻게 배정되는지는 보도자료에 없어 적지 않았습니다. 병무청 누리집 공지를 확인하세요

 

2. 접수 시각 계산 — 마감은 월요일 18시

⭐ 1차 / 시작 11/10(화) 10:00 / 마감 11/16(월) 18:00 / 접수 시간 6일 8시간(152시간) / 마감에서 발표까지 44시간(11/18 14:00)

⭐ 2차 / 시작 12/1(화) 10:00 / 마감 12/7(월) 18:00 / 접수 시간 6일 8시간(152시간) / 마감에서 발표까지 44시간(12/9 14:00)

⭐ 보도자료는 「7일간」이라고 적었지만 시작이 10시, 마감이 월요일 18시라 정확한 접수 시간은 6일 8시간입니다. 마지막 날은 18시에 끝나므로 퇴근·수업 뒤에 하려다 놓치기 쉽습니다(해석)

⭐ 1차 발표(11월 18일)와 2차 시작(12월 1일) 사이는 12일 20시간입니다(직접 계산)

⭐ 오늘(10월 19일)부터 1차 시작(11월 10일)까지는 22일입니다

 

3. 함정 — 선착순이 아니다

⚠️ 접수 첫날 10시에 서두르는 것이 답이 아닐 수 있습니다

⭐ 보도자료는 선발이 전공, 미선발 횟수, 나이, 직업선호 유형 등을 고려한다고 밝혔습니다. 먼저 눌렀다고 우선 배정된다는 설명은 없습니다

⭐ 특수학교와 사회복지시설은 관련 전공자를 우선해 선발합니다. 복무 경험이 경력과 이어지도록 한 취지입니다

⭐ 선택은 2지망까지입니다. 1지망과 2지망을 어떻게 정할지가 중요하고, 병무청이 실시간 접수현황을 보여 주므로 지원이 몰리는 곳을 보고 고를 수 있습니다

 

⭐ 항목별 비중(전공이 얼마나 중요한지, 미선발 횟수가 얼마나 반영되는지)은 보도자료에 없어 적지 않았습니다. 선발기준은 병무청 누리집 공지사항에서 확인할 수 있다고 안내했습니다

⭐ 한 번 신청한 뒤 수정이 가능한지도 확인하지 못했습니다

 

4. 신청 순서

⭐ 1단계 / 내 상태 확인 / 재학생·국외입영연기 중이면 1차, 소집대기 중이면 2차

⭐ 2단계 / 본인인증 수단 준비 / 병무청 간편인증·공동인증서·나라사랑이메일 인증 중 하나

⭐ 3단계 / 접수 기간 안에 접속 / 병무청 누리집(www.mma.go.kr) 또는 모바일 앱 · 마감은 월요일 18:00

⭐ 4단계 / 소집일자와 복무기관 2지망 선택 / 실시간 접수현황을 보고 복무기관을 고르기

⭐ 5단계 / 발표 확인 / 1차 11월 18일 14:00 · 2차 12월 9일 14:00

⭐ 신청은 무료입니다. 접수에 비용이 든다는 안내는 보도자료에 없습니다

⭐ 문의: 병무청 사회복무국 사회복무정책과 042-481-3007

 

5. 확인하지 못한 것

ℹ️ 아래는 공식 자료에서 확인하지 못해 적지 않았습니다

 

⭐ 소집일자 목록(몇 월 며칠 소집이 열리는지) — 보도자료에 없고 병무청 누리집 공지에서 확인해야 합니다

⭐ 1차 대상자가 1차에 신청하지 못했을 때 2차에 신청할 수 있는지 — 보도자료에 없습니다

⭐ 본인선택을 하지 않으면 어떻게 배정되는지 — 보도자료에 없습니다

⭐ 선발 항목별 비중(전공·미선발 횟수·나이·직업선호) — 확인하지 못했습니다

⭐ 신청 후 수정 가능 여부 — 확인하지 못했습니다

✅ 마무리

2027년도 사회복무요원 본인선택은 재학생·국외입영연기 중이면 11월 10일 10시부터 16일 18시까지(1차, 발표 18일 14시), 소집대기 중이면 12월 1일 10시부터 7일 18시까지(2차, 발표 9일 14시)입니다.

 

병무청 누리집이나 앱에서 소집일자와 복무기관을 2지망까지 고르고, 선발은 선착순이 아니라 전공·미선발 횟수 등을 고려합니다. 소집일자 목록과 미선택 시 배정 방식은 확인하지 못했으니 병무청 공지를 먼저 확인하세요.
