카카오페이머니·네이버페이 머니·토스머니에 충전해 두고 잊은 잔액이 있다면 오늘(10월 19일)부터 앱 알림을 받을 수 있습니다.

 

금융위원회(2026-10-15 보도자료)에 따르면 네이버파이낸셜·카카오페이·비바리퍼블리카(토스) 3사가 10월 19일부터 순차적으로 장기간 쓰지 않은 선불충전금을 연 1회 이상 알려 주고, 통지할 때 환급 방법도 함께 안내합니다.

 

2026년 8월 말 기준 통지 대상은 176만 명, 선불 255억 원입니다.

 

보도자료 원문과 붙임 「네·카·토 이용자 통지 및 환급 절차」, 각 사 고객센터 안내를 직접 열어 3사 기준을 비교하고, 내 잔액이 해당되는지·통지가 진짜인지 가리는 방법을 정리했습니다.

 

💳 먼저 정리

 

⭐ 시행 — 3사 모두 2026년 10월 19일부터 순차적으로 통지(개인별 수신 시점은 확인하지 못했습니다)

⭐ 통지 대상 — 카카오페이 1년 이상 · 네이버페이·토스 2년 이상 머니 사용 이력이 없고, 잔액이 카카오페이 1원 이상 · 네이버페이·토스 1,000원 이상

⭐ 환급 — 통지 수신 → 공식 앱 로그인 → 송금(계좌환급) 메뉴 → 계좌 선택·금액 입력 → 환급 진행(즉시)

⭐ 제약 없음 — 장기 미사용 분류는 관리 목적일 뿐 사용·환급에 제약이 없습니다

⭐ 통지 대상 규모는 176만 명·255억 원이고, 1인당 평균 약 14,500원입니다(255억 ÷ 176만, 직접 계산 · 이용자 중복 포함)

⭐ 토스머니는 고객센터 FAQ가 「앞으로 충전할 수 없다」고 안내해 보도자료와의 관계를 확인하지 못했습니다(5번)

⚠️ 「통지를 받았다」며 계좌정보를 묻는 문자는 사칭입니다

 

이용자 통지는 앱 알림·알림톡 등 공식 채널로만 발송됩니다.

 

출처가 불분명한 이메일·문자메시지에서 통지나 환급을 이유로 계좌정보 등을 요구하면 절대 응하지 마세요(금융위 보도자료). 환급은 공식 앱에 로그인해서만 진행합니다.

1. 3사 비교표 — 통지 대상·방법·환급 메뉴

⭐ 장기 미사용 기준 / 카카오페이: 1년 이상 머니 사용 이력 없음 / 네이버페이: 2년 이상(충전·결제 등 이력 없음) / 토스: 2년 이상 토스머니 사용 이력 없음

⭐ 잔액 조건 / 카카오페이: 1원 이상 / 네이버페이: 1,000원 이상 / 토스: 1,000원 이상

⭐ 통지 방법 / 카카오페이: 카카오톡 알림톡 / 네이버페이: 네이버톡톡 네이버페이 공식 계정 / 토스: 앱푸시

⭐ 환급 메뉴 / 카카오페이: 카카오페이 계좌 송금 메뉴 / 네이버페이: 네이버페이 송금 메뉴 / 토스: 계좌환급 메뉴

⭐ 선불 유효기간 / 카카오페이: 10년 / 네이버페이: 10년 / 토스: 없음

⭐ 고객센터 / 카카오페이: 1644-7405 · 카카오톡 1:1문의 / 네이버페이: 1588-3819 · helpcustomer@naver.com / 토스: 1599-4905 · support@toss.im

⭐ 3사 공통: 통지 주기는 연 1회 이상이고, 통지를 받은 뒤 공식 앱에 로그인해 환급을 진행하면 즉시 처리된다고 붙임 자료에 적혀 있습니다

⭐ 3사가 자체적으로 제도 개선에 앞장섰다고 금융위는 평가했고, 이 사례를 전자금융 업계에 전파할 계획이라고 밝혔습니다

 

2. 내 잔액은 통지 대상인가 — 날짜·금액 판정

오늘(2026년 10월 19일) 기준으로 마지막 사용일과 잔액에 가정값을 넣어 보았습니다(직접 계산, 실제 분류는 각 사가 정합니다).

 

⭐ 마지막 머니 사용일 2026-03-01 · 잔액 30,000원 / 카카오페이: 해당 안 됨(1년 미만) / 네이버페이·토스: 해당 안 됨

⭐ 마지막 머니 사용일 2025-06-01(2025-10-19 이전) · 잔액 500원 / 카카오페이: 해당(1원 이상) / 네이버페이·토스: 해당 안 됨(2년 미만)

⭐ 마지막 머니 사용일 2024-05-10(2024-10-19 이전) · 잔액 500원 / 카카오페이: 해당 / 네이버페이·토스: 해당 안 됨(잔액 1,000원 미만)

⭐ 마지막 머니 사용일 2024-05-10 · 잔액 12,000원 / 카카오페이: 해당 / 네이버페이·토스: 해당

⭐ 카카오페이는 2025년 10월 19일 이전, 네이버페이·토스는 2024년 10월 19일 이전이 마지막 사용일이면 사용 이력 조건을 채웁니다

⭐ 통지 대상이 아니어도 잔액이 있으면 사용·환급은 언제든 가능합니다. 분류는 통지 대상을 가르는 관리 기준일 뿐입니다

⭐ 유효기간 10년인 선불은 종전에는 만료 30일 전부터만 통지해, 약 9년 11개월 동안 통지 의무가 없었습니다(10년 − 1개월 = 119개월, 직접 계산)

 

3. 환급 순서와 수수료·한도

⭐ 1단계 / 앱 알림·알림톡이 오면 공식 앱을 직접 열어 로그인(링크 클릭 대신 앱 실행)

⭐ 2단계 / 카카오페이 「계좌 송금」 · 네이버페이 「송금」 · 토스 「계좌환급」 메뉴로 이동

⭐ 3단계 / 환급받을 계좌를 선택하거나 입력하고 환급 금액 입력

⭐ 4단계 / 환급 진행 — 붙임 자료 기준 즉시 처리

⭐ 네이버페이 / 인출은 「Npay 홈 > 송금」 · 송금 수수료 무료 · 등록한 간편결제 계좌로 입금 · 1,000원 이상은 1원 단위로, 1,000원 미만은 전액 송금만 가능 · 이벤트로 받은 포인트는 인출 불가(직접 충전한 머니만) · 본인 명의 계좌가 없으면 인출 불가

⭐ 카카오페이 / 카카오페이증권 계좌를 열면 모든 계좌송금 무료 · 미개설 시 「내 계좌」(연결 계좌·본인 명의 증권계좌) 송금은 무료, 그 외 계좌는 매월 1일 기준 10회 무료·초과 건당 500원

⭐ 토스 / 계좌 송금 한도(성인) 1회 200만 원·1일 1,000만 원은 확인했지만 토스머니 환급 전용 수수료·한도는 확인하지 못했습니다

⭐ 카카오페이는 환급 계좌가 카카오페이에 연결된 「내 계좌」이면 송금 수수료가 없다는 FAQ를 근거로, 본인 계좌로 환급받으면 수수료가 없을 가능성이 높습니다(해석 — 환급 전용 수수료 문구는 확인하지 못했습니다)

⭐ 카카오페이머니 잔액 한도는 본인 계좌 연결 시 200만 원, 미연결 50만 원, 증권계좌 개설 후 무제한입니다

⭐ 환급받지 않고 계속 써도 됩니다

 

4. 진짜 통지와 사칭 문자 구분

⭐ 채널 / 공식 통지: 카카오톡 알림톡 · 네이버톡톡 네이버페이 공식 계정 · 토스 앱푸시 등 공식 채널 / 의심해야 할 것: 출처가 불분명한 이메일·문자메시지

⭐ 내용 / 공식 통지: 잔액 보유 사실·유효기간·환급 안내 / 의심해야 할 것: 계좌정보 등을 요구

⭐ 대응 / 공식 통지: 공식 앱을 직접 열어 로그인해 확인 / 의심해야 할 것: 링크를 누르지 말고 절대 응하지 않기

⭐ 의심스러운 연락은 각 사 고객센터(카카오페이 1644-7405 · 네이버페이 1588-3819 · 토스 1599-4905)로 확인하세요

⭐ 금융감독원 콜센터는 1332입니다(보도자료 하단 안내, 통화료는 발신자 부담)

 

5. 확인하지 못한 것

ℹ️ 아래는 공식 자료에서 확인하지 못해 적지 않았습니다

 

⭐ 토스머니 보유분의 처리 — 토스 고객센터 FAQ는 「앞으로 토스머니 잔액을 충전할 수 없다」(성인 충전·보유 중단)고 안내하는데, 보도자료는 2년 미사용 1,000원 이상 보유자를 통지 대상으로 적습니다. 두 문서의 관계는 확인하지 못했으니 토스(1599-4905)에 확인하세요

⭐ 환급 한도(1회·1일)와 환급 수수료 — 네이버페이 인출 한도, 토스의 환급 수수료·한도, 카카오페이 환급 전용 수수료는 확인하지 못했습니다

⭐ 카카오페이 환급 소요 시간 — 붙임 자료의 「즉시」 외에 고객센터 FAQ의 소요일 표기는 확인하지 못했습니다

⭐ 개인별 통지 수신 시점 — 「10월 19일부터 순차」라고만 적혀 있습니다

⭐ 3사 외 다른 선불업자의 적용 여부 — 업계 전반에 사례를 전파하겠다는 설명만 있습니다
