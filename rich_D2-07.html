장마·집중호우철엔 도로가 순식간에 물바다가 되죠.

차가 물에 잠겼을 때 어떻게 하느냐에 따라 보상 여부와 금액이 완전히 달라집니다.

잘못 대응하면 자차보험이 있어도 못 받을 수 있어요. 침수 직후 대처부터 자차보험·전손·중고 침수차까지 정리했습니다.

목차

1. 침수 직후 절대 하면 안 되는 것

2. 자차보험으로 보상받기(단독사고 특약)

3. 전손·폐차·자동차세 환급

4. 중고 침수차 안 사는 법(카히스토리)

1. 침수 직후 절대 하면 안 되는 것

🚫 물에 잠긴 차, 절대 시동 걸지 마세요! 엔진에 물 들어간 상태서 시동=워터해머로 엔진 완전 파손. 게다가 시동으로 커진 손해는 보험사가 '확대손해'로 봐 보상 제한.

• 시동·전자장치 조작 금지(가능하면 배터리 단자 분리)

• 무리하게 빼지 말고 보험사 긴급출동(견인) 호출

• 침수 상태(수위·번호판·주변) 사진·영상 증거 확보

• 가입 보험사 콜센터에 즉시 사고 접수

2. 자차보험으로 보상받기(단독사고 특약)

침수는 자기차량손해(자차)로 보상. 단, 조건 있음.

⭐ '자기차량단독사고 특약'이 있어야 침수 보상됩니다! 2015년부터 자차에서 분리 판매 → 보험료 아끼려 이 특약 빼두면 자차 있어도 침수 보상 못 받을 수 있음. 내 증권 확인 필수.

• 창문·선루프 닫힌 상태서 침수 → 보상 O

• 창문·선루프 열어둔 상태 침수 / 통제·침수구역 알고도 진입 → 면책(보상 X)

• 자기부담금 있음(손해액 일정 비율), 차 안 물건은 자차로 보상 안 됨

3. 전손·폐차·자동차세 환급

수리비가 차량가액 넘으면 전손 → 보험사가 차량가액 보상.

• 침수 전손차는 판매 금지, 전손 통보일부터 30일 이내 폐차 의무

• ⚠️ 기한 내 폐차 안 하면 300만 원 이하 과태료

• 폐차·말소하면 미리 낸(연납) 자동차세 남은기간분 일할계산 환급(위택스 확인)

4. 중고 침수차 안 사는 법(카히스토리)

• 카히스토리(carhistory.or.kr)에서 침수차량 조회는 무료! 차량번호로 확인

• ⚠️ 한계: 보험 처리된 침수만 조회됨. 자비 수리 후 판 침수차는 안 잡힘 → 실물 점검 병행

• 실물 점검: 안전벨트 끝까지 당겨 진흙 확인, 시트레일·볼트 녹, 트렁크 스페어타이어 공간, 실내 곰팡이·냄새, 전기배선 부식

공식 확인

• 카히스토리(침수차 무료조회): https://www.carhistory.or.kr

• 손해보험협회: https://www.knia.or.kr

• 위택스(자동차세 환급): https://www.wetax.go.kr
