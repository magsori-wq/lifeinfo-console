★ "OTT 요금제, 지금 얼마예요?" 2026년 10월 13일에 각 서비스의 공식 요금 페이지를 직접 열어 확인했습니다.

넷플릭스(고객센터 요금표)와 디즈니+(공식 홈페이지)는 페이지를 바로 읽었고, 티빙·웨이브·쿠팡플레이는 공식 사이트를 브라우저로 열어 읽었습니다. 달라진 점이 꽤 많습니다.

디즈니+에는 광고형 요금제가 보이지 않고, 티빙의 광고형 스탠다드는 10월 6일부터 기간 한정 가격이며, 쿠팡플레이는 와우 회원이 아니어도 무료로 볼 수 있다고 공식 페이지가 안내합니다.

번들·연간 결제·넷플릭스 추가 회원은 공식 가격으로 직접 계산했고, 확인하지 못한 것은 맨 아래에 따로 밝혔습니다.

✅ 정리

⭐ 넷플릭스 : 광고형 스탠다드 월 7,000원 · 스탠다드 월 13,500원 · 프리미엄 월 17,000원 (연간 멤버십은 제공 안 함)

⭐ 티빙 : 광고형 스탠다드 월 5,500원 · 베이직 월 9,500원 · 스탠다드 월 13,500원은 기간 한정(2026.10.6~2027.1.31), 프리미엄 월 17,000원

⭐ 디즈니+ : 스탠다드 월 9,900원 / 프리미엄 월 13,900원(광고 없는 스트리밍), 연간은 99,000원 / 139,000원

⭐ 번들 : 디즈니+·티빙 월 18,000원(개별 합산 대비 5,400원 저렴) · 디즈니+·티빙·웨이브 월 21,500원

⭐ 쿠팡플레이 : 와우 회원이 아니어도 무료 시청 가능, 스포츠는 별도 스포츠 패스

1. 지금 요금표 — 다섯 곳 한눈에

⭐ 넷플릭스(2026.10.13. 고객센터 요금표) — 광고형 스탠다드 월 7,000원: 동시 2대·1080p·광고 포함 / 스탠다드 월 13,500원: 광고 없음·동시 2대·1080p / 프리미엄 월 17,000원: 광고 없음·동시 4대·4K HDR

⭐ 티빙(이용권 구독 페이지) — 광고형 스탠다드 월 5,500원(기간 한정 2026.10.6~2027.1.31) / 베이직 월 9,500원(기간 한정) / 스탠다드 월 13,500원(기간 한정) / 프리미엄 월 17,000원(Apple TV 제공)

⭐ 디즈니+(공식 홈페이지 요금 안내, 부가세 포함) — 스탠다드 월 9,900원·연 99,000원(최대 1080p·동시 2대) / 프리미엄 월 13,900원·연 139,000원(최대 4K·동시 4대)

⭐ 웨이브 — 웨이브×티빙 더블 이용권만 공식 페이지에 보임: 더블 광고형 스탠다드 월 7,000원 / 더블 베이직 월 13,500원 / 더블 스탠다드 월 15,000원 / 더블 프리미엄 월 19,500원

⭐ 쿠팡플레이 — 와우 회원이 아니어도 무료 시청 가능(공식 페이지), 일부 콘텐츠는 개별 구매·패스 가입, HBO는 와우 회원 전용, 스포츠는 스포츠 패스 가입 후 시청

넷플릭스는 신규·재가입 회원에게 베이식 멤버십을 더 이상 제공하지 않습니다. 디즈니+ 요금표에는 광고형 요금제가 없고 두 요금제 모두 "광고 없는 스트리밍"으로 적혀 있습니다.

티빙의 기간 한정 가격은 2027년 1월 31일까지이고 그 뒤 가격은 확인하지 못했습니다.

2. 번들이 얼마나 싼가 — 계산

디즈니+ 공식 안내와 티빙 공식 페이지의 가격을 그대로 계산했습니다.

⭐ 티빙 스탠다드 13,500원 + 디즈니+ 스탠다드 9,900원 = 개별 합산 23,400원 → 번들 월 18,000원, 월 5,400원 저렴(약 23%, 공식 표기 "최대 23% 절약"과 일치)

⭐ 티빙·웨이브·디즈니+ 3 PACK : 개별 합산 34,300원(티빙 공식 페이지 표기) → 번들 월 21,500원, 월 12,800원 저렴(약 37%)

⭐ 넷플릭스 스탠다드 + 티빙 스탠다드 + 디즈니+ 스탠다드를 따로 구독하면 13,500 + 13,500 + 9,900 = 36,900원 → 티빙·디즈니+는 번들로 바꾸면 13,500 + 18,000 = 31,500원, 월 5,400원(연 64,800원) 절약

⭐ 티빙·웨이브 더블 스탠다드 : 합산 24,400원 → 월 15,000원, 월 9,400원 저렴(티빙 공식 페이지 표기 기준)

번들은 월별 멤버십 기준 제휴 상품이라 번들 서비스별 이용 조건과 광고·화질은 상품마다 다릅니다.

3. 연간 결제는 어디서 되나

⭐ 디즈니+ 스탠다드 : 월 9,900원 × 12 = 118,800원 → 연간 99,000원, 19,800원 저렴(약 16.7%)

⭐ 디즈니+ 프리미엄 : 월 13,900원 × 12 = 166,800원 → 연간 139,000원, 27,800원 저렴(약 16.7%)

⭐ 넷플릭스 : 연간·수개월 단위·평생 멤버십은 제공하지 않음(고객센터 안내) — 월 결제만 가능

⚠️ "연간 결제가 월 결제보다 싸다"는 서비스마다 다릅니다. 디즈니+는 되고 넷플릭스는 안 됩니다. 티빙·웨이브의 연간 가격은 이번에 확인하지 못했습니다.

4. 넷플릭스 가족 밖 공유 — 추가 회원 계산

넷플릭스 고객센터는 계정을 넷플릭스 이용 가구 외의 사람과 공유할 수 없다고 안내합니다. 가구에 속하지 않는 사람은 추가 회원으로 등록할 수 있고, 요금은 초대한 사람이 결제합니다.

⭐ 추가 회원 요금 : 광고형 멤버십 1명당 월 4,000원 / 광고 없는 멤버십 1명당 월 5,000원

⭐ 등록 가능 수 : 광고형 1명 / 스탠다드 1명 / 프리미엄 최대 2명

가구 밖 두 명과 함께 광고 없이 보는 경우를 계산해 보면:

⭐ 프리미엄 17,000원 + 추가 회원 2명 × 5,000원 = 월 27,000원

⭐ 세 명이 각자 스탠다드를 구독하면 13,500원 × 3 = 40,500원

⭐ 차이 : 월 13,500원(세 명 합계 기준), 1인당으로 나누면 프리미엄 묶음이 월 9,000원, 각자 구독이 월 13,500원

5. 쿠팡플레이는 무료 시청부터

쿠팡플레이 공식 페이지는 와우 회원이 아니어도 무료로 시청할 수 있다고 안내하고, 일부 콘텐츠는 개별 구매 또는 패스 가입 후 시청할 수 있으며 HBO는 와우 회원 전용 혜택이라고 적었습니다.

스포츠는 스포츠 패스에 가입해야 볼 수 있습니다.

⭐ 와우 멤버십 월 7,890원 — 쿠팡 뉴스룸 2024년 4월 12일 보도자료 기준. 현재 가입 화면의 월회비 금액은 이번에 읽지 못했습니다

⭐ 스포츠 패스 월 16,600원(와우 회원 9,900원) — 쿠팡 뉴스룸 2025년 6월 19일 보도자료 기준(출시 안내). 현재 가격은 확인하지 못했습니다

쿠팡 와우를 쓰고 있다면 쿠팡플레이는 따로 구독하지 않아도 되는지부터 확인하세요.

6. 내 상황별 판단표

⭐ 혼자 가볍게 보고 광고가 괜찮다 — 티빙 광고형 5,500원(기간 한정)이나 넷플릭스 광고형 7,000원

⭐ 광고 없이 TV로 가족과 본다 — 넷플릭스 프리미엄(동시 4대·4K) 17,000원 또는 디즈니+ 프리미엄 13,900원(동시 4대·4K)

⭐ 티빙과 디즈니+를 둘 다 본다 — 따로 구독(23,400원)보다 번들 18,000원

⭐ 티빙·웨이브·디즈니+를 다 본다 — 3 PACK 21,500원이 개별 합산 34,300원보다 저렴

⭐ 디즈니+ 하나만 오래 본다 — 연간 99,000원(스탠다드)이 월 결제 118,800원보다 저렴

⭐ 넷플릭스를 가구 밖 사람과 나눈다 — 추가 회원 제도(광고 없는 멤버십 1명 5,000원)

⭐ 쿠팡플레이로 가볍게 본다 — 무료 시청부터, 스포츠는 패스 필요

7. 확인하지 못한 것

ℹ️ 공식 확인 실패 — 추측으로 채우지 않았습니다

⭐ 웨이브 단독 이용권(베이직·스탠다드·프리미엄) 월 요금 — 공식 이용권 페이지에서 더블 이용권만 보였고 '모든 이용권 보기'를 열지 못했습니다

⭐ 티빙 기간 한정 가격이 끝난 뒤(2027.2.1~)의 요금과 연간 이용권 가격

⭐ 쿠팡 와우 멤버십 현재 월회비 — 가입 화면에서 금액이 읽히지 않아 2024년 보도자료 금액만 표기했습니다

⭐ 쿠팡플레이 스포츠 패스 현재 가격

⭐ 통신사·카드 제휴 할인과 무료 제공 혜택의 현재 조건

⭐ 디즈니+ 광고형 요금제가 다른 경로(통신사 결합 등)로 제공되는지
