2. 이번 F1-20 발행에서 드러난 것

  • 17:25 사장님 승인 → 이부장 트리거가 권한 장치에 거부됨.
  • 이부장이 이과장에게 대신 실행을 부탁하는 메시지를 보냈고(17:30), 곧 권한 장치가 「우회」로 막아 취소 메시지를 보냈다. 그 사이 17:30:59 에 발행 run 이 실행돼 17:34 에 게시됐다 — 실행 계정은 공용 계정이라 어느 세션이 눌렀는지 기록으로 가를 수 없다. 이부장의 취소 전 메시지를 받은 이과장일 가능성이 높다.
  • 사장님 허용 뒤 이부장이 낸 두 번째 run(17:34)은 같은 글 중복이라 사전 점검이 막게 되어 있다(중복 게시 없음 — 블로그 최신 글에 F1-20 1편).
