경남 고성 당항포에서 2026 경남고성공룡세계엑스포가 9월 22일부터 11월 1일까지 41일간 열리고 있습니다.

평일엔 오후 5시면 문을 닫지만, 주말과 개천절 대체공휴일(10/5)·한글날(10/9)엔 밤 9시까지 야간개장을 합니다.

언제 가야 야간개장·야경까지 보는지, 입장료는 어떤 권종이 나에게 맞는지 요금표·야간개장 날짜·확인이 필요한 부분까지 정리했습니다.

목차

1. 운영기간·시간 — 평일과 야간개장 특별일의 차이

2. 입장료 총정리 (권종별 비교)

3. 사전예매 온라인 할인, 지금도 되나 — 확인 상태

4. 언제 가면 야간개장인가 — 남은 날짜 계산

✅ 정리

- 운영 9/22~11/1(41일), 평일 오후 5시·야간개장일(토일+10/5+10/9) 밤 9시 마감

- 요금은 현장권 대인 19,000원·소인 13,000원이 기준, 군민·단체·경로 등 할인 구분 있음

- 사전예매 온라인 할인(9/21 마감 보도)은 지금도 판매하는지 공식 미확인 — 놀티켓·네이버에서 직접 확인 필요

1. 운영기간·시간 — 평일과 야간개장 특별일의 차이

행사 기간은 9월 22일(화)~11월 1일(일), 41일간이며 장소는 경남 고성군 회화면 당항포관광지 일원입니다. 운영시간은 요일에 따라 다릅니다.

⭐ 운영시간 — 구분 : 대상 요일 : 운영시간 : 전시관 입장마감

- 주간개장 : 월~금(야간개장일 제외) : 09:00~17:00 : 17:00

- 야간개장 : 토·일 + 10/5(월·대체공휴일) + 10/9(금·한글날) : 09:00~21:00 : 21:00~22:00

⚠️ 평일에 야간개장을 기대하고 가면 낭패

10/6(화)·10/7(수)·10/8(목)처럼 평일이면 공휴일이 아닌 한 오후 5시에 문을 닫습니다. 야경이 목적이면 반드시 아래 4번 날짜표에서 요일부터 확인하고 움직이세요.

(보도에는 매주 토요일 불꽃쇼가 예정돼 있다고 나오지만, 공식 홈페이지엔 별도 일정 표기가 없어 방문 전 재확인을 권합니다.)

2. 입장료 총정리 (권종별 비교)

현장 구매 기준 공식 요금은 아래와 같습니다. 자신이 어느 할인 대상에 해당하는지부터 확인하세요.

⭐ 입장료 — 권종 : 대인 : 소인 : 대상

- 현장권 : 19,000원 : 13,000원 : 만 19~64세 / 만 36개월~만 18세

- 군민할인 : 14,000원 : 7,000원 : 고성군민(신분증·주민등록등본 등 확인)

- 단체할인 : 14,000원 : 7,000원 : 15인 이상(외국인 단체는 10인 이상)

- 기타할인 : 8,000원 : 5,000원 : 만 65세 이상, 장애인, 국가유공자 동반자 등

- 전기간통용권 : 80,000원 : 50,000원 : 행사 기간 중 여러 번 입장 가능

- 무료 : 면제 : 면제 : 만 36개월 미만, 심한 장애인(1~3급), 국가유공자 본인

하루만 가면 현장권, 65세 이상·장애인이면 신분증 지참하고 기타할인(현장권 대비 약 58% 저렴), 주말마다 들를 계획이면 전기간통용권을 따져보세요.

대인 기준 80,000원÷19,000원≈4.2회이므로 5회 이상 방문해야 현장권을 여러 번 사는 것보다 저렴합니다(4회까지는 오히려 현장권이 쌉니다). 주차는 무료입니다.

3. 사전예매 온라인 할인, 지금도 되나 — 확인 상태

행사 개막을 앞두고 놀(NOL)티켓·네이버에서 대인 15,500원·소인 7,500원(현장가 대비 각 약 18%·42% 할인)의 사전예매가 진행됐고, 보도에 따르면 사전예매 마감일은 9월 21일이었습니다.

⚠️ 확인 못 한 부분 — 추정으로 채우지 않습니다

사전예매 마감(9/21) 이후 온라인 구매가 아예 막혔는지, 할인폭만 줄어든 채 계속되는지는 공식 발표로 확인되지 않았습니다.

온라인 할인을 노린다면 놀티켓·네이버에서 직접 검색해 현재 판매 여부와 가격을 확인한 뒤 방문하시길 권합니다.

4. 언제 가면 야간개장인가 — 남은 날짜 계산

행사 시작일(9/22)부터 종료일(11/1)까지, 전체 기간 중 야간개장(밤 9시 마감)에 해당하는 날짜는 아래와 같습니다.

⭐ 야간개장일 — 주차 : 날짜

- 9월 마지막 주 : 9/26(토), 9/27(일)

- 10월 첫 주(연휴) : 10/3(토·개천절), 10/4(일), 10/5(월·대체공휴일)

- 10월 둘째 주 : 10/9(금·한글날), 10/10(토), 10/11(일)

- 10월 셋째 주 : 10/17(토), 10/18(일)

- 10월 넷째 주 : 10/24(토), 10/25(일)

- 10월 말~폐막 : 10/31(토), 11/1(일·폐막일)

즉 전체 41일 중 야간개장은 14일뿐입니다. 평일(공휴일 제외)에 방문하면 오후 5시 마감이라 야경은 볼 수 없으니, 토·일이나 10/5·10/9 중 하루를 골라 일정을 잡으시길 권합니다.
