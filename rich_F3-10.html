일본 면세 11월 1일 변경, 먼저 내고 출국 때 환급

일본 면세 제도가 2026년 11월 1일 구매분부터 「리펀드 방식」으로 바뀝니다.

 

지금까지는 면세점에서 세금을 뺀 가격으로 샀지만, 11월 1일부터는 세금이 포함된 가격으로 먼저 사고, 출국할 때 공항 세관에서 물품을 가지고 나가는 것이 확인된 뒤 소비세 상당액을 돌려받습니다.

 

일본 관광청·국세청·세관이 낸 안내를 2026년 10월 29일에 직접 열어 확인한 것만 적었고, 환급이 어떤 수단으로 언제 들어오는지는 면세점마다 달라 확인하지 못했습니다.

1. 일본 면세 변경 — 현행과 11월 1일부터 비교

⭐ 구매 가격 / 10월 31일까지 구매분(현행): 세금을 뺀 가격(면세 판매) / 11월 1일 구매분부터: 세금 포함 가격(과세 판매)

⭐ 돌려받는 시점 / 10월 31일까지 구매분(현행): 구매할 때 바로 면세 / 11월 1일 구매분부터: 출국 때 세관 확인 뒤 환급

⭐ 확인 기한 / 10월 31일까지 구매분(현행): 비교표에 해당 없음 / 11월 1일 구매분부터: 구매일로부터 90일 이내 출국 시

⭐ 소모품 / 10월 31일까지 구매분(현행): 구입 상한 50만 엔·특수 포장 / 11월 1일 구매분부터: 상한과 특수 포장 폐지, 일본 안에서 먹거나 쓰면 환급 불가

⭐ 최소 금액 / 10월 31일까지 구매분(현행): 5,000엔 이상 / 11월 1일 구매분부터: 변경 없음(같은 점포 1일 구입액 5,000엔 이상)

⭐ 구입 수량 / 10월 31일까지 구매분(현행): 비교표에 해당 없음 / 11월 1일 구매분부터: 출국 때 직접 소지해 가져갈 수 있는 수량만

⭐ 반출하지 않으면 / 10월 31일까지 구매분(현행): 면제된 소비세 징수 / 11월 1일 구매분부터: 면제된 소비세 징수, 벌칙 대상

표는 일본 관광청의 「수속 변경점 비교표」와 여행자용 안내를 한국어로 옮긴 것입니다.

 

구매 가격이 달라지므로 11월 1일 이후에는 같은 물건도 계산대에서 내는 금액이 더 큽니다(세금이 포함되므로). 그 금액은 출국 때 세관 확인 뒤 돌려받는 구조입니다.

 

 

2. 출국하는 날 순서

⭐ ① 구매할 때 / 할 일: 세금 포함 가격으로 구매, 환급 정보 등록 / 공식 안내 내용: 면세점에서 여권 제시, 신용카드 등 환급 정보를 등록(한국어 리플릿)

⭐ ② 공항 도착 / 할 일: 수하물을 맡기기 전에 면세 수속용 단말기로 이동 / 공식 안내 내용: 국제선 출발 로비에 단말기와 세관 검사 장소가 있고, 맡긴 뒤에는 수속할 수 없음

⭐ ③ 여권 제시 / 할 일: 산 물품을 모두 가지고 단말기에 여권 제시 / 공식 안내 내용: 화면에 검사 필요 여부 표시 — GREEN이면 수속 종료, RED면 세관 검사 장소에서 확인

⭐ ④ 수하물 위탁 / 할 일: 세관 확인을 끝낸 뒤 항공사 카운터로 이동 / 공식 안내 내용: 탑승 수속 전까지 확인을 마쳐야 함

⭐ ⑤ 환급 / 할 일: 세관 확인 뒤 환급 / 공식 안내 내용: 면세점 또는 위탁 환급 사업자가 진행, 방법은 면세점에 문의

일부 공항(나리타·하네다·간사이·주부·후쿠오카·신치토세·나하)은 단말기 대신 Visit Japan Web으로 수속할 수 있다고 안내돼 있습니다.

 

국내선에서 국제선으로 갈아타는 경우 일본을 떠나는 마지막 공항에서 수속해야 합니다.

 

 

3. 일본 면세 환급이 안 되는 경우 — 영수증 단위와 90일

ℹ️ 🧮 가상 사례 — 공식 리플릿의 영수증 예시 금액을 대입한 계산입니다 —

 

⭐ 물품 A / 금액: 3,000엔 / 출국 때 상태: 소지

⭐ 물품 B / 금액: 75,000엔 / 출국 때 상태: 소지

⭐ 물품 C / 금액: 13,000엔 / 출국 때 상태: 미소지(이미 소비하거나 놓고 옴)

⭐ 합계 / 금액: 91,000엔 / 출국 때 상태: 세관 확인은 영수증 1장 단위라 91,000엔어치 모두 환급 불가

같은 영수증에서 C를 가지고 있었다면 91,000엔 전체가 정상적으로 확인 대상이지만, C가 없으면 A·B(78,000엔)까지 포함해 91,000엔 전체가 환급 대상에서 빠집니다.

 

한 번 계산할 때 담은 물품은 묶음 하나로 확인된다는 뜻이라, 일본에서 먹어 치울 물건은 가능하면 따로 계산하는 편이 안전합니다(이 글의 판단이며 공식 권고 문구가 아닙니다).

 

ℹ️ 🧮 가상 사례 — 구매일에 90일을 더한 마지막 출국 날짜 계산입니다 —

 

⭐ 2026년 11월 1일(일) 구매 : 2027년 1월 30일(토)

⭐ 2026년 11월 20일(금) 구매 : 2027년 2월 18일(목)

⭐ 2026년 12월 10일(목) 구매 : 2027년 3월 10일(수)

구매일 다음 날부터 센 계산이고, 구매일을 1일로 세는지 등 세부 기준은 면세점이나 세관 안내를 확인하세요. 일본 관광청은 구매일로부터 90일 이내 출국 때 확인을 받아야 한다고 안내합니다.

 

 

4. 일본 면세 변경, 오해하기 쉬운 것

⭐ 10월 31일까지 구매분은 현행 방식입니다 — 11월 1일 구매분부터 새 방식이며, 10월 구매분을 11월 이후 출국에서 어떻게 처리하는지는 확인하지 못했습니다.

⭐ 수하물을 맡기고 나면 늦습니다 — 세관 확인은 맡기기 전에 해야 하고, 이미 맡긴 짐을 찾아 수속하는 것도 안 됩니다.

⭐ 시간이 부족하면 보상이 없습니다 — 탑승 수속까지 확인을 끝내야 하며 시간이 없어 못 떠나도 항공사·세관의 보상은 없습니다.

⭐ 일본에서 쓰면 환급이 안 됩니다 — 음식료·화장품 등을 일본 안에서 먹거나 쓰면 세관 확인(환급)을 받을 수 없습니다.

⭐ 단가 100만 엔 이상은 서류를 요구받을 수 있습니다 — 소비세를 뺀 단가가 100만 엔 이상이면 감정서나 보증서 제시를 요구받을 수 있습니다.

⚠️ 아래는 공식 자료에서 찾지 못해 적지 않았습니다

⭐ 환급 수단별 수수료와 입금 시점 — 면세점 또는 환급 사업자마다 다르다고만 안내돼 있습니다

⭐ 매장이 리펀드 방식 대응 점포인지 — 점포별로 확인해야 합니다

⭐ 공항별 단말기 위치 — 각 공항 안내 지도로 확인하세요

 

 

5. 영수증·여권·엔화 챙기기

세관 확인은 영수증 1장 단위로 이뤄지고, 단말기 앞에서는 산 물품과 여권을 함께 내야 합니다. 영수증과 여권, 엔화 동전을 한곳에 모아 두면 공항에서 꺼내기 편합니다.

 

환급과 직접 관련은 없는 보관 도구이고, 효과를 보장하는 것은 아닙니다.
