★ 휴대폰을 새로 개통하러 가면 얼굴 인증을 하라고 합니다. 싫으면 안 해도 되는지, 인증이 안 되면 개통이 막히는지가 가장 궁금하실 텐데요.

정부 발표를 보면 7월 6일에 단계적으로 시작해 10월에 시행이 마무리되는 일정입니다.

✅ 먼저 결론 4가지

⭐ 안면인증을 선택하면 최소 1차례(3회 시도)를 해야 다음 절차로 넘어갑니다

⭐ 얼굴 인증이 실패해도 다른 수단으로 본인이 확인되면 개통이 허용되고, 그 과정은 기록으로 남습니다

⭐ 대체 수단은 모바일신분증 앱(스마트폰 보유자), 당일 발급 주민등록초본(스마트폰 미보유자)입니다

⭐ 11월부터는 가입제한서비스를 계약 때 기본으로 제공한다는 계획입니다

1. 내 경우엔 어떤 인증을 쓰나 — 수단 3가지

⭐ 안면인증 / 대상: 누구나 선택 / 준비물: 본인 확인 서류(매장 안내 확인) / 다른 수단을 대체하나: 선택하면 최소 3회 시도 후 다음 절차

⭐ 모바일신분증 앱 / 대상: 스마트폰 보유자 / 준비물: 행정안전부 모바일신분증 앱 / 다른 수단을 대체하나: 안면인증이 안 될 때의 대체 수단

⭐ 당일 주민등록초본 / 대상: 스마트폰 미보유자 / 준비물: 당일 발급분 / 다른 수단을 대체하나: 스마트폰이 없을 때의 대체 수단

사업자와 매장마다 모바일신분증을 받는지는 다를 수 있어, 개통 전에 문의해 두는 것이 안전합니다.

⭐ 스마트폰이 있고 모바일신분증을 이미 발급받았다 — 안면인증이 안 될 때 대체 수단으로 앱 인증을 쓸 수 있습니다. 처음부터 앱을 고를 수 있는지는 발표에 없어 매장에 확인하세요

⭐ 스마트폰은 있지만 모바일신분증이 없다 — 안면인증을 시도하고, 안 되면 다른 수단으로 확인하게 됩니다

⭐ 스마트폰이 없다 — 그날 발급받은 주민등록초본을 챙기면 됩니다

2. 공식 문구, 창구에서는 무슨 뜻일까

정부 발표 문장을 그대로 읽으면 헷갈리는 부분이 있습니다. 개통 창구에서 이용자에게 어떤 의미인지 나란히 놓았습니다.

⭐ 횟수 / 공식 안내 문구: 안면인증 선택 시 최소 1차례(3회) 이행 / 실제로 의미하는 것: 한 번 시작하면 3번 시도하는 한 세트를 끝내야 다음 단계로 넘어감

⭐ 실패 / 공식 안내 문구: 다른 수단으로 본인 확인 시 일정 요건 하에 개통 허용, 과정 기록 / 실제로 의미하는 것: 인증이 안 돼도 개통이 막히는 건 아님. 다만 다른 방법으로 본인임이 확인돼야 하고 기록이 남음

⭐ 대체 / 공식 안내 문구: 모바일신분증 앱 인증 / 당일 발급 주민등록초본 / 실제로 의미하는 것: 스마트폰이 있으면 앱, 없으면 그날 발급받은 초본(발표 표현은 '당일 발급')

⭐ 시기 / 공식 안내 문구: 10월 시행 완료 / 실제로 의미하는 것: 제도가 없어진다는 뜻이 아니라, 단계적 시행이 끝나고 법적 근거가 정리된다는 뜻

핵심은 "얼굴 인증이 안 되면 개통이 안 된다"가 아니라 "본인 확인이 안 되면 안 된다"입니다.

3. 7월~11월 정부 일정표

과학기술정보통신부가 6월 30일 발표한 휴대전화 부정사용 방지 대책의 일정입니다. 대포폰·보이스피싱 범죄에 개통 단계부터 대응하겠다는 취지입니다.

⭐ 7월 6일 / 정부 발표 내용: 안면인증 단계적 시행 시작 / 일반 이용자에게 의미: 개통 창구에서 얼굴 인증 안내를 받음

⭐ 8월 / 정부 발표 내용: 대체 수단을 더한 다중인증체계 검토 / 일반 이용자에게 의미: 인증 방법이 늘어날 수 있음(결과는 확인 못 함)

⭐ 9월 / 정부 발표 내용: 주민등록초본 위·변조 자동확인 연계 / 일반 이용자에게 의미: 초본으로 인증할 때 위조 여부를 자동 점검

⭐ 10월 / 정부 발표 내용: 전기통신사업법 시행령 개정으로 안면인증 법적 근거 명확화, 단계적 시행 완료 / 일반 이용자에게 의미: 시범성 운영이 끝나고 제도로 자리 잡는 시점

⭐ 11월 / 정부 발표 내용: 가입제한서비스(msafer.or.kr)를 계약 시 기본 제공 / 일반 이용자에게 의미: 내 명의 새 회선 개통을 막는 장치가 기본값이 됨

⚠️ 계획 일정입니다. — 위 표는 6월 30일 발표 기준입니다. 이 글을 쓴 10월 15일 시점에 시행령 개정이 실제로 끝났는지는 확인하지 못했습니다.

4. 11월 가입제한서비스, 지금 해도 될까

가입제한서비스(msafer.or.kr)는 지금은 이용자가 직접 신청해야 하고, 정부는 11월부터 계약할 때 기본으로 제공하겠다는 계획입니다.

💡 🔎 기다릴 필요가 있을까 — 기본 제공은 11월 계획이고, 그 전까지는 직접 신청해야 효과가 있습니다. 명의도용이 걱정되는 분은 지금 신청해도 손해될 이유가 없습니다. 개인정보 유출 뒤 명의 보호 방법은 아래 글도 참고하세요.

※ 주의 — 서비스의 정확한 적용 범위와 신청·해제 방법은 발표에 자세히 없어 확인하지 못했습니다. msafer.or.kr 에서 직접 확인하세요.

5. 개통 가기 전 체크리스트

⭐ 1. 스마트폰에 모바일신분증이 발급돼 있는지 확인

⭐ 2. 없다면 본인 확인 서류와, 스마트폰이 없는 경우 당일 발급 주민등록초본 준비

⭐ 3. 매장·사업자에 어떤 인증 수단을 받는지 미리 문의

⭐ 4. 개통 뒤 내 명의 회선 현황과 가입제한서비스 설정 여부 확인

6. 확인하지 못한 것

공식 발표 원문에서 찾지 못해 적지 않은 항목입니다. 추측으로 채우지 않았습니다.

⭐ 번호이동·기기변경에도 같은 절차가 적용되는지

⭐ 전면 시행일 — 발표는 「10월 단계적 시행 완료」까지만 안내합니다

⭐ 10월 시행령 개정이 실제로 완료됐는지

⭐ 얼굴 정보를 어떻게 처리하는지에 대한 세부 내용

개통을 앞두고 있다면 가입하려는 통신사나 알뜰폰 사업자의 최신 안내를 한 번 더 확인하세요.

✅ 마무리

휴대폰 개통 안면인증은 7월 6일 단계 시행을 거쳐 10월에 시행 완료·법적 근거 정리를 앞두고 있습니다.

인증이 안 돼도 다른 수단으로 본인이 확인되면 개통되지만, 모바일신분증을 미리 준비해 두면 인증이 막혔을 때 대안이 됩니다. 11월 기본 제공 전까지 명의도용이 걱정되면 가입제한서비스를 직접 신청해 두세요.
