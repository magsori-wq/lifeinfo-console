동호회·정기모임·가족여행 회비, 누가 냈는지 얼마 남았는지 불투명하면 총무만 스트레스죠.

카카오뱅크 모임통장이면 모임원 누구나 잔액·입출금을 실시간으로 봐서 '투명 공유'가 돼요.

만드는 법부터 초대·체크카드·해지까지 정리했습니다.

모임통장 장점

모임장 개인 명의 입출금 계좌에 회비 조회·관리·멤버 관리 기능을 더한 서비스입니다.

• 모임원 누구나 잔액·입출금 내역 실시간 확인 → 투명한 회비 관리

• 누가 얼마 냈는지 납입 현황이 한눈에

• 총무·모임장이 따로 정산하느라 받는 스트레스 ↓

• 모임 이름·대표 이미지로 전용 통장처럼 운영

※ 잔액에 소액 이자(2026년 6월 기준 연 0.10%, 세전 / 변동 가능)

만드는 방법 (모임장 기준, 1~2분)

1) 카카오뱅크 앱 → 상품 목록에서 '모임통장' 선택

2) 모임 이름·대표 이미지 설정 후 개설

3) 카카오톡으로 모임원 초대 링크 공유

4) 모임원이 수락하면 '함께 보기' 멤버로 등록 → 잔액·내역 공유

💡 모임장 조건: 카카오뱅크 본인 명의 입출금 계좌 보유 + 만 17세 이상

(계좌 없으면 카뱅 가입·입출금통장 개설 먼저)

모임원 초대·가입 조건

• 카뱅 계좌 없는 사람도 초대장은 받을 수 있음

• 단, 실제 참여(함께 보기)하려면 카카오뱅크 앱 설치·회원가입 필요

• 입금은 본인 계좌에서 모임통장으로 이체

회비 관리 + 모임 체크카드

• 회비 규칙(정해진 날 자동이체)·공지·지출 메모로 정산 편하게

• 모임통장에 연결된 모임 체크카드 발급 시 카드 결제가 통장 내역에 자동 기록

• ★ 모임 체크카드: 5만 원 이상 결제 시 하루 1회 300원 또는 3,000원 랜덤 캐시백

(발급은 모임장 / 카드 쓰려면 연결된 모임통장 유지)

알아둘 점

• 모임통장은 모임장 개인 명의 계좌 기반 → 출금 권한은 모임장(신뢰 중요,

단 모든 입출금이 투명하게 보여 임의 사용은 바로 드러남)

• 모임 해체 시 잔액 정산 후 기능 해제·계좌 해지(체크카드 발급했으면 함께 정리)

• 회비 자동 출금은 안 됨 → 모임원이 직접 이체/자동이체
