보건복지부가 2026년 10월 30일부터 복지로(www.bokjiro.go.kr)의 기초연금 온라인 신청 절차를 바꿨습니다.

 

배우자가 곁에 없어도 문자로 받은 누리집 주소에서 동의할 수 있고, 임대차계약서처럼 바로 구하지 못하는 서류는 신청을 먼저 끝낸 뒤 나중에 낼 수 있습니다.

 

보도자료를 2026년 10월 30일에 직접 열어 확인한 내용만 적었고, 추후 제출 기한처럼 원문에 없는 것은 「확인 못 한 것」으로 따로 뺐습니다.

 

✅ 정리

⭐ 언제부터 / 2026년 10월 30일부터 시행(복지로 온라인 신청)

⭐ 배우자 동의 / 배우자에게 문자로 동의용 누리집 주소가 가고, 배우자가 언제든 바로 동의

⭐ 서류 / 공적자료로 연계되지 않는 임대차계약서 등은 추후 제출 선택 가능(서류 준비 후 온라인 또는 방문 제출)

⭐ 탈락 대비 / 신청할 때 수급희망 이력관리를 함께 신청 가능(탈락한 사람의 5년간 매년 2회 이력조사)

⭐ 확인 못 한 것 / 추후 제출 기한, 복지로 화면 메뉴, 문자 주소 유효시간

 

⭐ 2025년 온라인 신청 중단 사유 2,467건 중 구비서류 937건(38%)과 정보제공 동의 917건(37.2%)이 대부분이었습니다.

⭐ 두 사유를 합치면 1,854건으로 중단의 약 75%입니다((937+917)÷2,467, 본 글 계산).

목차

1. 무엇이 바뀌었나 — 변경 전·후 3가지

2. 내 상황이면 중단할까, 먼저 신청할까

3. 가상 사례 — 배우자가 입원 중이고 계약서가 아직 없을 때

4. 먼저 신청해도 달라지지 않는 것

 

1. 무엇이 바뀌었나 — 변경 전·후 3가지

⭐ 배우자 동의 / 바뀌기 전: 서류 제출 등으로 해야 했음 / 10월 30일부터: 배우자에게 문자 메시지로 누리집 주소가 가고, 언제든 바로 동의

⭐ 임대차계약서 등 별도 서류 / 바뀌기 전: 사본을 파일로 첨부해야만 온라인 신청 가능 / 10월 30일부터: 추후 제출 선택 시 신청 완료 후 서류를 준비해 온라인 또는 방문 제출

⭐ 수급희망 이력관리 / 바뀌기 전: 별도 신청서를 작성해야 했음 / 10월 30일부터: 기초연금 신청 시 동시 신청 가능

기초연금은 신청자와 배우자의 소득·재산 수준에 따라 수급 여부가 결정되기 때문에 두 사람의 금융정보 제공 동의가 필요하고, 재산을 증빙하는 서류를 내야 하는 경우도 많습니다.

 

보도자료는 이 두 가지가 온라인 신청이 낮았던 이유라고 설명합니다. 2025년 신청자 887,431명 중 온라인 신청은 29,903명(3.4%)이었습니다.

 

 

2. 내 상황이면 중단할까, 먼저 신청할까

ℹ️ 🧭 판단 기준 — 보도자료의 변경 내용을 상황에 대입한 본 글의 정리이며, 공식 안내문이 아닙니다 —

 

⭐ 배우자가 멀리 있거나 병원·요양시설에 있음 / 신청을 멈추지 말고 배우자에게 동의 문자를 보내 같은 시간·장소 없이 동의 / 먼저 확인: 배우자 휴대전화로 문자를 받을 수 있는지

⭐ 임대차계약서 등 서류가 아직 없음 / 신청을 끝내고 추후 제출 선택 / 먼저 확인: 제출 기한(보도자료에 없음), 복지로 안내

⭐ 배우자 휴대전화가 없거나 문자를 못 받음 / 보도자료에 이 경우의 처리는 없음 / 먼저 확인: 가까운 국민연금공단 지사·주민센터에 방법 문의

⭐ 예전에 신청했다가 탈락함 / 기존 탈락자의 처리는 확인 못 함 / 먼저 확인: 이력관리 대상인지 공단에 문의

⭐ 탈락할 것 같아 신청이 망설여짐 / 신청 시 수급희망 이력관리를 함께 신청하면 5년간 매년 2회 이력 조사 / 먼저 확인: 가능성이 확인되면 신청한 것으로 간주(보도자료)

판단의 핵심은 이것입니다. 예전에는 서류와 동의가 막히면 신청 자체를 접는 사람이 많았습니다.

 

이제 두 지점은 「신청 뒤」로 미룰 수 있으니, 막힌 이유가 이 둘이라면 접지 말고 신청부터 끝내는 쪽이 보도자료의 취지에 맞습니다.

 

다만 「먼저 신청」은 서류를 안 내도 된다는 뜻이 아닙니다. 보도자료는 서류를 준비한 후 제출한다고 적었고, 제출하지 않으면 어떻게 되는지·언제까지 내야 하는지는 적지 않았습니다.

 

그래서 서류가 없다면 신청과 동시에 제출 일정을 잡아 두는 편이 안전합니다.

 

 

3. 가상 사례 — 배우자가 입원 중이고 계약서가 아직 없을 때

ℹ️ 🧮 가상 사례 — 보도자료의 변경 내용을 한 사람의 상황에 대입한 예시입니다(실제 인물·금액 아님) —

 

⭐ ① 신청 시작 / 10월 29일까지: 복지로에서 시작 / 10월 30일부터: 복지로에서 시작

⭐ ② 배우자 동의 / 10월 29일까지: 배우자가 요양병원에 있어 서류 동의를 받으러 가야 해서 멈춤 / 10월 30일부터: 배우자 휴대전화로 동의 문자를 보내 배우자가 병실에서 동의

⭐ ③ 임대차계약서 / 10월 29일까지: 집주인에게 사본을 받기 전까지 첨부 불가 → 신청 포기 / 10월 30일부터: 추후 제출을 고르고 신청을 완료

⭐ ④ 이후 / 10월 29일까지: 처음부터 다시 / 10월 30일부터: 사본을 받으면 온라인 또는 방문으로 제출

이 사례에서 달라지는 것은 멈추는 지점이 두 군데 사라진다는 점입니다. ②에서는 만나지 않고, ③에서는 서류 없이 신청 단계를 넘깁니다.

 

실제로 이 사례처럼 처리되는지는 복지로 화면에서 확인해야 하며, ④의 기한은 보도자료에 없습니다.

 

 

4. 먼저 신청해도 달라지지 않는 것

⭐ 수급 여부는 그대로 신청자와 배우자의 소득·재산 수준으로 정해집니다. 절차만 쉬워진 것이지 선정 기준이 바뀐 것이 아닙니다.

⭐ 서류가 필요 없어진 것이 아닙니다 — 「추후 제출」이지 「제출 생략」이 아닙니다.

⭐ 배우자 동의 자체는 그대로 필요합니다 — 방식이 서류에서 문자로 바뀌었습니다.

⭐ 소득인정액·선정기준액·자격 요건은 이 글에서 다루지 않았습니다. 자격과 계산은 아래 함께 보면 좋은 글의 기초연금 총정리를 확인하세요.

⚠️ 확인하지 못한 것 — 추측으로 채우지 않았습니다 (2026-10-30 기준)

⭐ 추후 제출 기한과, 기한 안에 못 냈을 때의 처리 — 보도자료 본문에 없습니다(첨부 안내 자료는 이미지로만 열려 읽지 못했습니다)

⭐ 복지로 화면의 메뉴 이름과 클릭 순서 — 보도자료에 없습니다

⭐ 배우자 동의 문자 주소의 유효 시간, 문자를 못 받을 때의 대안 — 보도자료에 없습니다

⭐ 신청 접수일이 지급 시작 시점에 어떻게 반영되는지 — 이번 보도자료에 없고 따로 확인하지 못했습니다

⭐ 문의 전화 — 보도자료 본문에는 번호가 없어 적지 않았습니다. 복지로나 가까운 국민연금공단 지사에 문의하세요
