  ⛔ **네이버 게시 전에는 인스타 캡션·쓰레드 원고를 내지 않는다** (2026-09-14 결재).

     · 막히면 `batchboard now` 로 '네이버 대기' 를 남기고 다음 준비로 간다
  🔴 네이버 원문에도 「🔗 다른 채널에서도 보기」 교차링크를 넣는다 —
     2026-09-10 A3-12 실측 사고: 쓰레드는 게시됐는데 네이버 글에서
     그리로 가는 길이 없었다. `naver.py` 게이트가 이제 경고한다.

━━━ 막히면 ━━━
  1. 거부·실패 문구를 **한 글자도 바꾸지 말고** `batchboard now` 에 남긴다
  2. 사람 손이 필요하면 결재함에도:
     python -m studio.watch add --id blocked-pub0926h116 --owner user --due <오늘> \
        --what "<무엇이 왜 막혔나>" --cmd "<사장님이 그대로 실행할 한 줄>"
  3. **그 자리에 남아 이 배치를 계속 폴링한다.** 다른 배치로 옮기지 않는다.
  4. **다른 세션(3.·이과장)의 도움이 필요하면 주소를 찾아 직접 보내지 마라.**
     `batchboard now` 의 --what 에 `🤝 <세션>에게 요청: <무엇을·왜·언제까지>` 로 남긴다.
     이부장이 그 세션 지시서로 옮기고 깨운다. 주소를 찾느라 멈추지 않는다.


━━━ 스스로 확인한다 — 관제탑이 깨워주기를 기다리지 마라 ━━━
  🔴 2026-09-07 사장님: *"이과장이 지시서를 스스로 확인하게 할 수가 없는거야?"*
     **있다.** 세션은 턴이 끝나면 잠들지만, `Monitor` 도구는 그 사이에도 돈다.
     관제탑이 승인 감시에 쓰는 그 도구를 **너도 쓸 수 있다.**

  ⚡ **지금 이 Monitor 를 걸어라** (description: 내 지시서 변경 · persistent: true):
     last=$(python -m studio.orderhash 이과장 2>/dev/null); \
     while true; do date +%s > webapp/.lee_heartbeat; \
     cur=$(python -m studio.orderhash 이과장 2>/dev/null); \
     if [ -n "$cur" ] && [ "$cur" != "$last" ]; then \
     echo "ORDER-CHANGED $last -> $cur"; last="$cur"; fi; sleep 20; done

  이 지문은 **네 앞 지시서 전부**를 요약한다. 다음 넷 중 하나만 생겨도 바뀐다:
     ① 새 지시서가 생김  ② 지시서가 갱신됨
     ③ **승인 도장이 찍힘**(사장님이 CP 에서 누르시면 자동으로 찍힌다)
     ④ 항목이 done 으로 바뀜
  이벤트가 오면 무엇이 걸렸는지 본다:  python -m studio.orderhash 이과장 --why
  🔴 이것을 걸어 두면 **관제탑이 죽어 있어도** 네가 먼저 안다.

━━━ 어긋나면 어느 쪽을 따르나 ━━━
  🔴 **지시서와 메시지가 다르면 — 나중에 갱신된 지시서가 이긴다.**
     판정은 보드의 `order_at`(등록 시각)으로 한다. 기억으로 고르지 마라.
     메시지는 「보드를 읽어라」는 **깨우기**이지 지시가 아니다.
  🔴 **지시서에 「사장님이 승인하셨다」가 적혀 있으면 그것이 승인이다.**
     사장님께 다시 확인하지 마라 — 자리에 안 계시면 그 재확인으로 일이 선다.
     실측 2026-09-10: 제휴 링크 하나를 재확인하느라 다음 글 발행 전체가 섰다.
  ⚠️ 다만 **되돌릴 수 없는 것**(라이브 발행·삭제)에 승인 표기가 없으면 물어라.
     묻지 말라는 것은 **이미 승인이 적힌 것**을 다시 묻지 말라는 뜻이다.

━━━ 이 지시서가 전부다 ━━━
  🔴 관제탑은 **메시지로 지시하지 않는다.** 채널이 둘이면 어느 것이 최신인지
     알 수 없고, 메시지는 이력에 안 남아 다음 세션이 못 본다.
     새 지시는 이 배치의 지시서가 **갱신되는 것**으로만 온다.
     python -m studio.batchboard order --id pub0926h116
