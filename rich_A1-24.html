⭐ 응모권 — 수도권 3만 원당 1장(최대 10장) · 비수도권 3만 원당 2장(최대 20장) · 지역은 거주지가 아니라 실제 결제 장소 기준

⭐ 당첨 — 총 5,600명·17억 원 규모 · 12월 초 앱 개별 통지 · 당첨금은 12월 중 디지털온누리상품권으로 지급

⭐ 1인 최대 30장은 비수도권 30만 원(20장) + 수도권 30만 원(10장) = 결제 60만 원에서 채웁니다(직접 계산)

⭐ 응모권 총수와 개별 당첨 확률은 원문에 없어 계산하지 않았습니다

;font-weight:800;color:#1a1a1a;border-left:5px solid #c2410c;padding-left:10px;margin:0 0 6px">1. 부산·경남 독자 계산표 — 결제액별 응모권



 

⭐ 2만 9천 원 / 0단위 / 0장

⭐ 3만 원 / 1단위 / 2장

⭐ 5만 8천 원 / 1단위(2만 8천 원은 버려짐) / 2장

⭐ 9만 원 / 3단위 / 6장

⭐ 15만 원 / 5단위 / 10장

⭐ 30만 원 / 10단위 / 20장(상한 도달)

⭐ 60만 원 / 20단위 / 20장(상한 초과분은 늘지 않음)

⭐ 비수도권은 30만 원에서 20장 상한에 닿습니다. 월 60만 원을 부산에서 써도 응모권은 20장이라, 상한 이후의 결제는 응모권을 늘리지 않습니다(직접 계산)

⭐ 수도권은 3만 원당 1장이라 30만 원에서 10장 상한에 닿습니다

⭐ 두 지역을 모두 채우면 1인 최대 30장이고, 필요한 결제액은 비수도권 30만 원 + 수도권 30만 원 = 60만 원입니다

 

;font-weight:800;color:#1a1a1a;border-left:5px solid #c2410c;padding-left:10px;margin:0 0 6px">2. 함정 — 지역별 각각 합산



 

⭐ 서울 2만 9천 원 + 부산 2만 9천 원 / 수도권 0단위 · 비수도권 0단위 / 0장(합계 5만 8천 원인데도)

⭐ 서울 3만 원 + 부산 2만 9천 원 / 수도권 1단위 → 1장 · 비수도권 0단위 / 1장

⭐ 서울 14만 원 + 부산 14만 원 / 수도권 4단위(12만 원) → 4장 · 비수도권 4단위(12만 원) → 8장 / 12장

⭐ 부산 28만 원 + 부산 1만 원(같은 지역) / 비수도권 29만 원 → 9단위 → 18장 / 18장

⭐ 지역 구분은 거주지가 아니라 실제 결제 장소입니다. 서울에 사는 사람이 부산 가맹점에서 쓰면 비수도권으로 칩니다

⭐ 한 달 동안 몇 번에 나눠 쓰더라도 같은 지역끼리는 누적되므로, 소액 결제도 같은 지역에서 모으면 단위를 채울 수 있습니다

 

;font-weight:800;color:#1a1a1a;border-left:5px solid #c2410c;padding-left:10px;margin:0 0 6px">3. 상금 구조 — 1등은 비수도권만

⭐ 1등 / 3,000만 원 / 10명 / 3억 원

⭐ 2등 / 200만 원 / 40명 / 0.8억 원

⭐ 3등 / 100만 원 / 850명 / 8.5억 원

⭐ 4등 / 10만 원 / 4,700명 / 4.7억 원

⭐ 합계 / 5,600명 / 17억 원

⭐ 네 등수의 금액×인원을 더하면 17억 원이라 공식 「5,600명, 17억 원 규모」와 일치합니다

⭐ 1등은 비수도권에서 결제해 받은 응모권 보유자 중에서만 추첨합니다. 수도권 거주자도 비수도권 매장에서 결제하면 대상이고, 수도권에서만 결제하면 1등 추첨 대상이 아닙니다

⭐ 2~4등은 전국 응모권을 합쳐 추첨하고, 한 사람이 중복 당첨될 수 없습니다(가장 높은 등수 1회)

⭐ 당첨금은 디지털온누리상품권으로 지급되고, 제세공과금 22%가 부과되지 않습니다

 

;font-weight:800;color:#1a1a1a;border-left:5px solid #c2410c;padding-left:10px;margin:0 0 6px">4. 신청 절차와 제외 결제

⭐ 신청 방법 / 디지털온누리 앱에서 개인정보 제공 동의(10월 15일 09:00부터). 11월 15일까지 한 번만 동의하면 동의 시점과 무관하게 행사기간 전체 결제가 인정됩니다

⭐ 대상 / 만 19세 이상 디지털온누리 앱 이용자

⭐ 인정 결제 / 오프라인 가맹점에서 디지털온누리 상품권으로 결제

⭐ 제외 결제 / 온라인 가맹점 결제 · 지류 온누리상품권

⭐ 당첨 확인 / 12월 초 앱 개별 통지 · 12월 중 지급

⭐ 문의 / 중기부 소상공인성장촉진과 044-204-7830 · 전용 콜센터 1668-4319

⭐ 코리아 그랜드 페스티벌(10월 29일~11월 15일, 18일간, 10개 부처 참여) 개막 전 소비촉진 이벤트로 열렸습니다. 같은 기간 할인 행사는 아래 「함께 보면 좋은 글」의 K-세일페스타 글에서 다뤘습니다
