🔗 먼저 밝혀 드립니다 — 이 게시물은 네이버 브랜드커넥트 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다. 구매 가격이 오르지는 않습니다.

수능 준비물 — 화면 있는 시계·보조배터리, 안 내면 부정행위

★ 수능 전날 가방을 싸다 보면 "이 시계 괜찮나?", "텀블러는?", "보조배터리는 두고 가야 하나?" 하는 물건이 꼭 생깁니다.

평가원 시행세부계획에서 반입 금지 물품과 시험 중 휴대 가능 물품을 가려 보면 기준은 하나입니다. 통신·결제 기능, 전자식 화면표시기, 충전식 물품은 전부 안 됩니다.

✅ 먼저 결론 4가지

⭐ 입실 완료는 1교시 08:10까지 — 가져왔다면 그 전에 감독관에게 제출

⭐ 통신·결제 기능, 전자식 화면표시기, 충전식 물품은 전부 반입 금지 — 꺼 둬도 같습니다

⭐ 시계는 시침·분침이 있고 화면·통신·결제 기능이 없는 아날로그만 가능

⭐ 반입 금지 물품을 제출하지 않으면 부정행위로 간주 — 해당 시험 무효(휴대폰 등을 이용하면 1년 응시정지)

1. 입실 시각 — 교시별

⭐ 1교시 : 08:10까지(1교시를 선택하지 않은 수험생 포함)

⭐ 2·3·4·5교시 : 매 교시 시험 시작 10분 전까지

1교시 시작 전 제출이 필요한 물건이 있다면 08:10 입실 전에 감독관에게 건네야 합니다. 입실 직전에 가방을 정리하면 늦기 쉽습니다.

2. 이미 가져왔다면 — 제출 방법과 처리 기준

반입 금지 물품을 불가피하게 가져온 경우 1교시 시작 전에 감독관에게 제출하고, 응시하는 모든 영역·과목의 시험이 끝난 뒤 돌려받습니다. 제출하지 않으면 부정행위로 간주합니다.

⭐ 1교시 시작 전에 감독관에게 제출 : 시험 종료 후 반환(부정행위 아님)

⭐ 반입 금지 물품을 가지고도 제출하지 않음(9호) : 부정행위 — 당해 시험만 무효인 경미한 유형(6~10호)에 해당

⭐ 휴대 가능 물품 외 물품(시험 중 소지) : 적발 시 압수, 불응하면 부정행위 처리 가능. 일부 품목은 적발 즉시 부정행위 처리

⭐ 휴대폰·무선기기를 보거나 이용(3호) : 시험 무효 + 다음 해 1년간 응시자격 정지(1~5호)

💡 🔎 핵심 구분 — "가져온 것"과 "쓴 것"은 다릅니다. 반입 금지 물품을 갖고 있다가 제출하지 않은 경우는 해당 시험 무효, 휴대폰 등을 보거나 이용한 행위는 응시자격 정지까지 갑니다. 의심스러우면 시작 전에 제출하는 쪽이 가장 안전합니다.

3. 헷갈리는 물건 판정표

⭐ 스마트워치 / 판정: 불가 / 근거(공고 문구): 통신·결제 기능 물품 예시

⭐ 디지털(LCD·LED) 손목시계 / 판정: 불가 / 근거(공고 문구): 전자식 화면표시기가 있는 시계

⭐ 시침·분침 아날로그 시계 / 판정: 가능 / 근거(공고 문구): 결제·통신·화면표시기가 모두 없는 시계

⭐ 화면 표시되는 텀블러 / 판정: 불가 / 근거(공고 문구): 화면표시기 물품 예시

⭐ 일반 텀블러·보온병 / 판정: 공고에 없음 / 근거(공고 문구): 휴대 가능 목록에 없고, 시험 중 휴대 가능 물품 외 물품은 쉬는 시간만 휴대 가능

⭐ 보조배터리 / 판정: 불가 / 근거(공고 문구): 충전식 물품 예시

⭐ 이어폰(유선 포함 여부) / 판정: 공고에 명시 없음 / 근거(공고 문구): 통신 기능 물품 예시에 이어폰이 들어 있음

⭐ 돋보기·귀마개·방석 / 판정: 감독관 판단 / 근거(공고 문구): 매 교시 감독관이 부정행위 가능성을 검사해 결정

⭐ 보청기·인공와우·연속혈당측정기 등 / 판정: 사전 점검 후 가능 / 근거(공고 문구): 신체조건·의료상 필요 물품은 매 교시 감독관 사전 점검

⭐ 마스크(여분 포함) / 판정: 사전 확인 후 가능 / 근거(공고 문구): 감독관 사전 확인

🚫 필기구는 "더 가져가도 되는 것"이 아닙니다. — 개인 지참이 되는 필기구는 검은색 컴퓨터용 사인펜·흑색 연필·흰색 수정테이프·지우개·샤프심(흑색 0.5㎜)뿐이고 그 외 필기구는 개인 휴대 불가입니다.

1교시 시작 전 시험실에서 검은색 컴퓨터용 사인펜과 샤프를 일괄 지급합니다.

4. 못 가져가는 물건 3묶음

공고는 반입 금지 물품을 "시험장에 가지고 올 수 없는 물품(시험 시간, 쉬는 시간 불문하고 적발 시 부정행위 처리)"으로 정의합니다.

시험 중에 쓰느냐, 어떤 기능을 쓰느냐와 상관없이 모든 전자기기는 원칙적으로 반입 금지입니다.

⭐ ① 통신·결제 / 기준: 통신(블루투스 포함)·결제 기능이 있는 모든 물품 / 공고가 든 예: 휴대폰, 스마트워치, 스마트안경, 태블릿, 이어폰

⭐ ② 화면표시기 / 기준: 전자식 화면표시기(LCD·LED 등)가 있는 모든 물품 / 공고가 든 예: 전자사전, 화면표시기가 있는 텀블러, 시계

⭐ ③ 충전식 / 기준: 기타 충전식 물품 일체 / 공고가 든 예: 전자담배, 보조배터리

기능을 안 쓰고 꺼 둬도 반입 금지입니다. "스마트워치는 껐으니 괜찮다"가 흔한 착각 중 하나입니다.

5. 가방 싸기 체크리스트

⭐ 1. 신분증·수험표 — 전날 현관 가까이에 꺼내 두기

⭐ 2. 검은색 컴퓨터용 사인펜·흰색 수정테이프·흑색 연필·지우개·샤프심 — 필기구는 이 범위 안에서만

⭐ 3. 시계 — 시침·분침이 있고 화면·통신·결제 기능이 전혀 없는 것인지 직접 확인

⭐ 4. 텀블러·보온병 — 화면 표시 기능 유무 확인(공고에 일반 텀블러 허용 문구는 없음, 쉬는 시간 사용)

⭐ 5. 집에 둘 것 — 스마트워치·이어폰·보조배터리·전자담배·전자사전

⭐ 6. 의료상 필요한 기기(보청기·혈당관리기기 등) — 감독관 사전 점검 준비

6. 확인하지 못한 것

ℹ️ 못 찾아서 적지 않은 것

⭐ 평가원 사이트의 원 공고 게시글 주소 — 공고 전문은 학교 게시판에 전재된 본문으로 읽었고, 원 게시글은 직접 열어 보지 못했습니다

⭐ 2026년 8월판 안내서 PDF 본문 — 받았지만 글자 추출이 되지 않아 내용을 확인하지 못했습니다

⭐ 일반 텀블러·유선 이어폰의 허용 여부 — 공고 문구에 명시가 없어 판정하지 않았습니다

⭐ 시험장별 보관 방식 — 공고에 없습니다

사인펜은 미리 한 자루 더 — 필기구 고를 때

수능 필기구는 개인 지참이 가능한 범위가 정해져 있고(검은색 컴퓨터용 사인펜·흑색 연필 등), 1교시 전에 시험실에서도 사인펜을 일괄 지급합니다.

그래도 평소 쓰던 손에 익은 사인펜을 예비로 챙기고 싶다면 아래 기준만 보세요.

⭐ 색 : 검은색 컴퓨터용 사인펜이어야 합니다 — 공고의 개인 지참 가능 필기구 문구 기준

⭐ 용도 : OMR 마킹용이라 심이 너무 굵거나 번지지 않는 것이 편합니다

⭐ 주의 : 필기구는 공고의 지참 가능 목록 안에서만 — 색·종류 규정이 바뀌면 공식 안내를 다시 확인하세요
